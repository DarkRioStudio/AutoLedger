# AutoLedger App Icon Tools

This folder contains deterministic local tooling for regenerating AutoLedger app icon bitmap assets.

## Goal

The iOS icon uses a square composition, while tvOS uses a wide layered image stack and visionOS uses a solid image stack. Reusing the iOS lightning bolt directly on other platforms made the bolt look too thin after platform-specific scaling and layering.

The generator keeps the same visual elements:

- blue / teal background
- wallet card body
- coin
- lightning bolt
- small sparkles

But it redraws each platform from a platform-specific layout so the lightning bolt remains thick and legible.

## Generate

```bash
python3 tools/app-icons/generate_app_icons.py
```

Generated assets:

- iOS main AppIcon light / dark / tinted PNGs
- Apple Watch AppIcon PNG sizes
- tvOS App Icon image stack and App Store image stack layers
- visionOS AppIcon solid image stack layers

## Validate

```bash
python3 tools/app-icons/validate_app_icons.py
```

The validator checks:

- required PNG files exist
- platform-specific PNG dimensions match the asset catalog
- tvOS / visionOS front lightning layers have enough alpha coverage to avoid becoming a thin line

## Preview

```bash
python3 tools/app-icons/preview_app_icons.py
```

The preview sheet renders current assets with platform-shaped masks:

- iOS / Mac Catalyst: rounded rectangle
- Apple Watch: circle
- tvOS: wide rectangle
- visionOS: circle

## Notes

- The scripts do not change bundle identifiers, signing, entitlements, schema, or marketing version.
- Preview composites should still be inspected manually before App Store submission.
- Top Shelf images are not regenerated by this tool.
