# AutoLedger App Preview Script - zh-Hans

## Length

15-20 seconds. Keep the final video under 30 seconds.

## Style

- Real App UI
- Light motion
- Local highlights
- Short copy
- No abstract brand film
- No CG-heavy treatment
- No features that are not present in the app

## Storyboard

### 0-3s - Pain Point

Visual:

Several fictional payment screenshots, receipts, and expense cards stack or slide into view.

Copy:

```text
每天花钱，不想手动记？
```

### 3-8s - Screenshot Recognition

Visual:

A payment screenshot enters AutoLedger. The UI highlights amount, merchant, category, and time, then shows a ready-to-save record.

Copy:

```text
截图账单，一键识别
```

### 8-12s - Voice Quick Entry

Visual:

The text "午饭 28 元" appears as a voice-style input. AutoLedger turns it into a ready record.

Copy:

```text
说一句话，快速记账
```

### 12-16s - Apple Watch

Visual:

Apple Watch quick add or recent records screen appears beside the iPhone. The iPhone updates with the same recent record.

Copy:

```text
抬腕也能记一笔
```

### 16-20s - Monthly Report

Visual:

The monthly report screen shows category stats, trends, and frequent merchants.

Copy:

```text
月报统计，一眼看清
```

## Notes

- Design for silent playback.
- Keep text away from key UI controls.
- Use only fictional payment and receipt material.
- Avoid debug text, simulator UI, or test environment labels.
