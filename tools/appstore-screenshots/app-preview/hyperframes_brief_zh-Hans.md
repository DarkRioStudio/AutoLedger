# Hyperframes Brief - AutoLedger App Preview zh-Hans

## Goal

Create a 15-20 second iPhone App Store Preview video using real AutoLedger UI screenshots and deterministic keyframes.

The video should communicate:

- Screenshot-based expense recognition
- Voice-style quick entry
- Apple Watch quick logging
- Monthly spending overview
- Apple ecosystem continuity

## Visual Direction

- Clean, light, modern, Apple ecosystem feel
- Real App UI first
- Card slide-ins, gentle zooms, local highlights, and lightweight gesture hints
- No exaggerated 3D
- No game trailer style
- No abstract brand film
- No invented or unreleased product behavior

## Input Assets

Primary:

- iPhone store screenshots
- iPhone raw screenshots
- Apple Watch screenshots

Optional:

- Fictional payment screenshot mock
- Fictional receipt mock
- AutoLedger app icon

Never use:

- Real payment screenshots
- Real receipts
- Real account names
- Real card numbers
- Real order numbers
- Real phone numbers
- API keys, certificates, profiles, or private keys

## Recommended Output Files

```text
app_preview_iphone_zh-Hans_v001.mp4
app_preview_iphone_zh-Hans_v001.mov
```

## Recommended Keyframe Folder

```text
keyframes/
  preview_00_opening.png
  preview_01_ocr.png
  preview_02_voice.png
  preview_03_watch.png
  preview_04_report.png
```

## Motion Notes

- Keep text readable on mobile App Store pages.
- Use fast but calm pacing.
- Use a single warm background family consistent with screenshots.
- Highlight amount, merchant, category, and time only when those fields are visible in the UI.
- Avoid showing permissions, camera, microphone, network, iCloud, or LLM loading states.

## Delivery Review Checklist

- 15-20 seconds.
- Works without sound.
- Does not show unreleased features.
- Does not show real private financial data.
- Does not show debug or test labels.
- Main message is clear within the first 5 seconds.
