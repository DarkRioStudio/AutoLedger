## 4. 发布结论

- **结论：⏳ 待真机验证后判定**

## 5. 版本亮点

1. **Gemma 端侧 LLM**：MediaPipe LLM Inference 接入 Gemma-2 2B，自建 CDN 分发，SHA-256 校验，推理后自动释放内存
2. **模型体验增强**：下载进度修复、异步懒加载、Intent 并行预热、Extension 进程安全防护、AI 增强开关
3. **月报升级**：分类 Donut 图、近 6 月趋势柱图、TOP5 商户排行、自定义分类独立聚合
4. **异常消费检测**：按近 3 个完整月份分类月均值识别偏高支出，阈值可在设置中调整
5. **云闪付 / 银联适配**：新增来源枚举、分享 Bundle ID 映射和基础交易详情解析样本
6. **订阅管理增强**：年度总览、月均成本、年付节省建议、订阅编辑
7. **软删除持久化**：最近删除写入 SQLite，重启后仍可恢复，彻底删除才物理移除

## 6. 回滚方案

- 触发条件：新版本导致核心记账链路不可用、SQLite 数据异常、启动崩溃、OCR 入账大面积失败
- 回滚步骤：切回 v1.1.0 tag，重新构建并安装；若已执行 v1.2.0 数据库迁移，`deleted_at` 空列可保留，旧版本读取既有字段不受影响
- 影响评估：丧失 Gemma 端侧 LLM、月报图表增强、异常消费检测、云闪付 / 银联适配、订阅编辑与软删除跨会话能力；核心记账、订阅识别、分类学习、反馈链路可回退到 v1.1.0 行为
- 数据兼容：`deleted_at` 为新增列；订阅年付价和备注存放在 UserDefaults 侧表；回退不会删除用户交易数据
