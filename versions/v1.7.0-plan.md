# v1.7.0 版本计划：Pro 自动化扩展

更新日期：2026-06-30
文档状态：Draft
内部开发线：v1.7.0
App Store 对外版本：ASC 1.6.0
承接版本：v1.6.4
关联文档：`versions/v1.6.4-plan.md`、`docs/autoledger-personal-pro-design.md`、`docs/pro-access-audit.md`

## 0. 定位

`v1.6.4` 的 Pro 内容主要围绕酒店水单、邮箱候选、专属收件箱、批量候选和高级去重，解决的是酒店消费模块里的重复劳动。

`v1.7.0 / ASC 1.6.0` 承接更广义的 Pro 自动化扩展，把 Pro 从酒店水单自动化推进到全账本效率层：

> 免费版继续完成完整记账流程，Pro 帮用户在账本增长后更快查找、发现异常、生成月结资料，并批量应用规则。

## 1. 目标范围

本版本实现 `v1.6.4` Pro 页面路线图预告中的非酒店模块能力。

### 1.1 高级搜索

目标：让 Pro 用户可以跨账本、酒店消费、附件线索和交易字段组合查找记录。

计划能力：

- 金额区间搜索。
- 日期区间搜索。
- 商户 / 酒店 / 来源 / 分类组合筛选。
- 附件、水单、邮箱候选线索筛选。
- 保存常用搜索条件。

免费边界：

- 基础关键字搜索继续免费。
- 查看、编辑、删除历史账单继续免费。

### 1.2 订阅异常提醒

目标：从基础订阅列表升级为可解释的异常检测。

计划能力：

- 订阅涨价提醒。
- 疑似重复订阅 / 重复扣费提醒。
- 周期异常提醒。
- 未来 7 / 30 / 90 天续费压力汇总。
- 年度订阅成本预测。

免费边界：

- 基础订阅记录、手动维护和基础提醒继续免费。

### 1.3 月结导出包

目标：把月底整理从“用户自己导出再拼资料”升级为 Pro 自动生成可复核资料包。

计划能力：

- Excel / PDF 月结包。
- 分类统计、商户排行、来源排行。
- 酒店水单附件索引。
- 账本 / 分类 / 商户 / 时间范围筛选导出。
- 脱敏导出选项。

免费边界：

- 基础 CSV / JSON 导出、备份和恢复继续免费。

### 1.4 高级规则自动应用

目标：把用户已经修正过的商户、分类和低置信度模式批量应用到历史与未来记录。

计划能力：

- 商户别名规则批量应用。
- 分类修正规则批量应用。
- 低置信度结果集中复核队列。
- 历史记录一键预览与应用。
- 可撤销的批量规则执行。

免费边界：

- 单条商户、分类、备注和金额编辑继续免费。

## 2. 工程边界

本版本应继续遵守 `v1.6.4` 已冻结的 Free / Pro 原则：

- 不把手动记账、单张截图识别、手动酒店水单导入、基础订阅、基础月报、基础导出、备份恢复、历史查看编辑删除放入 Pro gate。
- Pro gate 只拦截新的自动化、批量整理、异常检测和高级导出能力。
- 到期后不锁历史数据，只暂停新的 Pro 自动化能力。
- 服务器成本能力继续使用服务端 entitlement 校验，客户端 gate 只作为本地 UI 边界。

## 4. 测试与验收

自动回归：

- Pro policy 回归确认 `advancedSearch`、`subscriptionAnomalyDetection`、`monthlyExportPackage`、`advancedRuleAutomation` 在 `v1.7.0` 实现后有明确 gate。
- 免费能力回归确认基础搜索、基础订阅、基础导出、历史查看编辑删除不被 gate。
- 高级搜索回归覆盖组合筛选、空结果、跨账本口径和酒店水单附件线索。
- 订阅异常回归覆盖涨价、重复扣费、周期异常和未来续费压力。
- 月结导出回归覆盖导出内容、脱敏选项、附件索引和无附件 fallback。
- 高级规则回归覆盖预览、应用、撤销和低置信度集中复核。

人工 smoke：

- 未订阅用户可以看到 Pro 说明和免费替代路径。
- 已订阅用户可以完成四类 Pro 自动化入口。
- 订阅过期后历史结果仍可查看、编辑和基础导出。
- App Review 截图和文案不暗示基础记账或历史数据被锁。

## 5. 非目标

- 不实现团队版 / Business。
- 不实现会计协作。
- 不把 Worker 变成用户邮箱代登录服务。
- 不自动正式入账。
- 不锁历史数据。
- 不改变 `Support Developer` 赞助内购。
