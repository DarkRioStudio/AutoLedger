# v1.7.0 版本计划：实时 OCR 票据扫描与 Pro 自动化扩展

更新日期：2026-07-01
文档状态：Draft
内部开发线：v1.7.0
App Store 对外版本：ASC 1.6.0
承接版本：v1.6.4
关联文档：`versions/v1.6.4-plan.md`、`docs/autoledger-personal-pro-design.md`、`docs/pro-access-audit.md`

## 0. 定位

`v1.6.4` 的 Pro 内容主要围绕酒店水单、邮箱候选、专属收件箱、批量候选和高级去重，解决的是酒店消费模块里的重复劳动。

`v1.7.0 / ASC 1.6.0` 承接两条主线：

1. 把首页“票据扫描”从当前拍照后识别升级为实时 OCR 扫描；不支持实时扫描时，回退到现有拍照识别照片 / 相册导入路径。
2. 承接更广义的 Pro 自动化扩展，把 Pro 从酒店水单自动化推进到全账本效率层。

> 免费版继续完成完整记账流程，Pro 帮用户在账本增长后更快查找、发现异常、生成月结资料，并批量应用规则。

## 1. 目标范围

本版本优先完成首页票据扫描体验升级，并实现 `v1.6.4` Pro 页面路线图预告中的非酒店模块能力。

### 1.1 首页实时 OCR 票据扫描

目标：用户点击首页“票据扫描”后，默认进入实时 OCR 取景框，对准纸质小票、支付凭证或屏幕上的账单即可看到识别状态；当系统或设备不支持实时 OCR 时，自动回退到当前拍照识别照片路径。

计划能力：

- 首页“票据扫描”默认打开实时 OCR 扫描界面，而不是先打开系统相机拍照。
- 识别过程中显示取景框、文字命中状态和“识别到账单信息”的轻提示。
- 对识别文本做短时间稳定 / 去抖，避免每一帧都触发解析。
- 用户确认后将稳定 OCR 文本送入既有 `LedgerTextInterpreter` / `LedgerStore.importRecognizedText` 流程，继续进入待确认账单，不自动正式入账。
- 支持手动切换到“拍照识别照片”和“从相册选择”，方便弱光、长票据、屏幕反光或实时识别失败时使用。
- 对不支持实时 OCR 的环境自动 fallback：不支持 VisionKit 实时扫描、相机不可用、权限被拒绝、Mac Catalyst、模拟器能力缺失或系统报告扫描不可用时，回到现有 `CameraPicker` / `PhotosPicker` 路径。

建议工程方案：

- 新增 `LiveReceiptScannerView`，优先使用 VisionKit 实时文字扫描能力；用 `#if canImport(VisionKit)` 与平台条件隔离，避免影响 Mac Catalyst / 截图模式构建。
- 新增 `ReceiptScanMode` 或等价状态：`.liveOCR`、`.cameraPhoto`、`.photoLibrary`、`.unsupportedFallback`。
- 新增 `ReceiptScanCapability` 探测：相机权限、实时扫描支持、实时扫描可用状态和当前平台。
- 实时 OCR 输出只保存短期内存态，不落库、不上传、不写入调试记录原文；用户确认导入后才沿用现有调试 / 导入链路。
- 复用当前 `OCRService` 和 `CameraPicker` 作为 fallback，不重写拍照识别照片链路。

免费边界：

- 实时 OCR 票据扫描属于基础记账入口，继续免费。
- 单张截图识别、拍照识别照片、相册导入、手动确认和历史查看编辑删除继续免费。
- 不把实时扫描放入 Pro gate。

验收口径：

- 支持实时扫描的 iPhone 上，首页“票据扫描”进入实时 OCR 取景框。
- 实时识别到有效账单文本后，用户确认可生成待确认账单字段。
- 权限拒绝、实时扫描不可用、无相机或 Mac Catalyst 环境下，入口能自然回退到拍照识别照片 / 相册导入，不出现死路。
- 相册截图入口仍保留，不被实时扫描替代。
- 扫描过程中不自动保存账单，仍需要用户确认。

### 1.2 高级搜索

目标：让 Pro 用户可以跨账本、酒店消费、附件线索和交易字段组合查找记录。

计划能力：

- 金额区间搜索。
- 日期区间搜索。
- 商户 / 酒店 / 来源 / 分类组合筛选。
- 附件、水单、邮箱候选线索筛选。
- 保存常用搜索条件。

免费边界：

- 基础关键字搜索继续免费。
- 查看、编辑、删除历史账单继续免费。

### 1.3 订阅异常提醒

目标：从基础订阅列表升级为可解释的异常检测。

计划能力：

- 订阅涨价提醒。
- 疑似重复订阅 / 重复扣费提醒。
- 周期异常提醒。
- 未来 7 / 30 / 90 天续费压力汇总。
- 年度订阅成本预测。

免费边界：

- 基础订阅记录、手动维护和基础提醒继续免费。

### 1.4 月结导出包

目标：把月底整理从“用户自己导出再拼资料”升级为 Pro 自动生成可复核资料包。

计划能力：

- Excel / PDF 月结包。
- 分类统计、商户排行、来源排行。
- 酒店水单附件索引。
- 账本 / 分类 / 商户 / 时间范围筛选导出。
- 脱敏导出选项。

免费边界：

- 基础 CSV / JSON 导出、备份和恢复继续免费。

### 1.5 高级规则自动应用

目标：把用户已经修正过的商户、分类和低置信度模式批量应用到历史与未来记录。

计划能力：

- 商户别名规则批量应用。
- 分类修正规则批量应用。
- 低置信度结果集中复核队列。
- 历史记录一键预览与应用。
- 可撤销的批量规则执行。

免费边界：

- 单条商户、分类、备注和金额编辑继续免费。

## 2. 工程边界

本版本应继续遵守 `v1.6.4` 已冻结的 Free / Pro 原则：

- 不把手动记账、单张截图识别、手动酒店水单导入、基础订阅、基础月报、基础导出、备份恢复、历史查看编辑删除放入 Pro gate。
- 不把首页实时 OCR 票据扫描放入 Pro gate；它是对现有拍照 / 相册单张识别的基础体验升级。
- Pro gate 只拦截新的自动化、批量整理、异常检测和高级导出能力。
- 到期后不锁历史数据，只暂停新的 Pro 自动化能力。
- 服务器成本能力继续使用服务端 entitlement 校验，客户端 gate 只作为本地 UI 边界。

## 4. 测试与验收

自动回归：

- 实时 OCR 扫描 capability 回归覆盖支持、不可用、权限拒绝、无相机和 Mac Catalyst fallback 分支。
- 首页票据扫描回归确认实时 OCR 输出走既有 `LedgerTextInterpreter` / 待确认账单流程，不自动正式入账。
- 现有拍照识别照片和相册导入回归继续通过，确保 fallback 不退化。
- Pro policy 回归确认 `advancedSearch`、`subscriptionAnomalyDetection`、`monthlyExportPackage`、`advancedRuleAutomation` 在 `v1.7.0` 实现后有明确 gate。
- 免费能力回归确认基础搜索、基础订阅、基础导出、历史查看编辑删除不被 gate。
- 高级搜索回归覆盖组合筛选、空结果、跨账本口径和酒店水单附件线索。
- 订阅异常回归覆盖涨价、重复扣费、周期异常和未来续费压力。
- 月结导出回归覆盖导出内容、脱敏选项、附件索引和无附件 fallback。
- 高级规则回归覆盖预览、应用、撤销和低置信度集中复核。

人工 smoke：

- iPhone 真机点击首页“票据扫描”，确认优先出现实时 OCR 取景框，并能对纸质小票 / 屏幕账单生成待确认账单。
- 关闭相机权限或使用不支持实时扫描的环境，确认自动回到拍照识别照片 / 相册导入路径。
- 未订阅用户可以看到 Pro 说明和免费替代路径。
- 已订阅用户可以完成四类 Pro 自动化入口。
- 订阅过期后历史结果仍可查看、编辑和基础导出。
- App Review 截图和文案不暗示基础记账或历史数据被锁。

## 5. 非目标

- 不实现团队版 / Business。
- 不实现会计协作。
- 不把实时 OCR 扫描做成后台持续扫描或自动入账。
- 不上传相机画面、OCR 原文或小票图片到云端。
- 不移除相册截图入口。
- 不把 Worker 变成用户邮箱代登录服务。
- 不自动正式入账。
- 不锁历史数据。
- 不改变 `Support Developer` 赞助内购。
