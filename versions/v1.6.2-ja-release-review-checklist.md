## 1. 审校边界

本清单用于 `GOAL-1950`，目标是把日文 UI、Widget、App Intents、截图和识别语言包推进到可人工审校状态。本文不替代母语审校结论，也不代表可以直接提交 ASC。

本轮已具备工程门禁：

- `python3 scripts/check_localization_coverage.py`
- `bash scripts/run_golden_regression.sh`
- `bash scripts/run_offline_regression.sh`
- `python3 scripts/check_l10n_release_smoke.py`

## 3. App Intents / Shortcuts

审校范围：

- `OpenMonthlyReportIntent`
- `OpenLedgerProfileIntent`
- `StartReceiptScanIntent`
- `OpenQuickAddIntent`
- `QuickLedgerIntent`
- `ClipboardImportIntent`
- `VoiceLedgerIntent`
- `ParseLedgerTextIntent`
- `ImportLedgerJSONIntent`

检查项：

- `ja.lproj/Localizable.strings` 中 title / description / short title / launched 文案自然。
- `AutoLedgerShortcuts` 日文推荐短语包含 `で記録`、`レシートスキャン`、`今月の統計`、`台帳` 等核心词。
- 推荐短语数量不超过系统 AppShortcut metadata 上限，酒店待确认入口当前不注册为推荐短语。

## 4. Widget

检查范围：

- 今日支出 Widget。
- 本月月报 Widget。
- 默认写入账本、Top 分类、最近账单、即将续费、快速记一笔。
- 分类 / 来源短标签。

检查项：

- 日文 Widget 文案不回退到英文。
- small / medium / large family 中日文不会截断主要金额和按钮。
- `autoledger://quick-add` 点击后仍进入主 App 新增账单 sheet。

## 5. 识别语言包与 Golden

当前日文语言包覆盖：

- 金额：`¥1,080`、`￥`、`JPY`、千分位 `,`、0 小数位。
- 日期：`yyyy/MM/dd`、`yyyy-MM-dd`、`yyyy年M月d日`。
- 金额标签：`合計`、`小計`、`税込合計`、`消費税`、`割引`、`預り金`、`返金`、`お釣り`。
- 商户标签：`店舗`、`加盟店`、`店名`、`販売者`。
- 商户排除词：`注文番号`、`取引番号`、`端末番号`、`部屋番号`、`税番号`、`会員番号`。
- OCR hint：`ja-JP` + `en-US`。

新增正式 golden cases：

- `core_ja_receipt_total_merchant`
- `core_ja_cafe_category`

人工审校时需要继续补充真实但已脱敏的日文便利店、交通、餐饮、电子支付和非账单样本。社区共享样本必须 opt-in、脱敏、可撤回，并进入 reviewed pack 后再合入。

## 6. 截图 / ASC / TestFlight

检查项：

- `tools/appstore-screenshots/config/screenshots.json` 的 `ja` 场景标题和副标题不截断。
- ASC Promotional Text、Description、Keywords、What's New 不提未开放功能。
- TestFlight notes 明确酒店邮箱导入需要用户主动触发，不自动读取邮箱。
- Review Notes 可通过 Demo Mode 测试酒店邮箱导入，不要求审核员登录真实邮箱。

## 7. 发布前人工证据

发布前至少保留以下证据：

- `ja` 语言主 App 账本、酒店消费、设置、Widget 和 App Intents 截图。
- `bash scripts/run_golden_regression.sh` 输出。
- `bash scripts/run_offline_regression.sh` 输出。
- 日文母语审校反馈或确认记录。
- 若使用真实样本补充 golden case，保留脱敏前后差异说明，不提交原始敏感图片或完整邮箱内容。
