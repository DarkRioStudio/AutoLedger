## 4. 判定口径

- 构建失败：不通过
- 离线回归失败：不通过
- 主路径截图导入、编辑、删除、恢复任一失败：不通过
- 月报图表无法渲染或与账本数据明显不一致：不通过
- 异常检测明显误报且阈值设置不生效：不通过
- 云闪付 / 银联基础样本解析失败：不通过
- 订阅编辑保存后丢失核心字段：不通过
- 软删除跨会话恢复失败：不通过
- Gemma 模型不可下载或不可用：不阻断核心记账，但需在发布说明中标记为已知限制并确保规则解析可用
- 服务端反馈自动化失败：建议修复但不阻断 App 核心发布

## 5. 已知限制（非阻断）

- Foundation Models 在国行设备不可用
- Gemma 模型约 2.5 GB，首次下载依赖 CDN 网络质量和设备存储空间
- MediaPipe `LlmInference` 当前有 SDK 弃用警告，后续需关注 LiteRT LM 迁移
- 云闪付 / 银联 OCR 版式多样，本版仅建立基础样本，仍需外测继续扩充
- 异常消费检测依赖至少 3 个完整月份的历史数据，早期用户数据不足时不会产生有效提醒
- 年付价和订阅备注以 UserDefaults 侧表保存，不进入 `subscriptions` 表结构
- 最近删除默认加载最近 50 条，暂未实现批量清空或保留期限设置
