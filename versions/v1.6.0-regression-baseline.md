更新日期：2026-06-24

App Store / ASC 对外版本：1.5.0
对应计划：`versions/v1.6.0-plan.md`

## 1. 范围

本 baseline 用于 `GOAL-1770` 发布前 smoke 收口，覆盖当前代码侧命令级门禁和人工发布门禁。

`v1.6.0` 的主发布线仍是 iPhone / iPad / Apple Watch / Mac Catalyst。tvOS / visionOS 已有第一版只读展示代码，但是否随 ASC 1.5.0 正式开放，取决于 Xcode Cloud、TestFlight、CloudKit Production schema 和平台素材的人工检查结果。

## 3. 已知 Warning

- `AppFormatters`、App Intent logger、部分 Intent / OCR / CloudKit 调用存在 Swift 6 / deprecated warning。
- `VoiceLedgerIntent` / `QuickLedgerIntent` 有 MainActor 隔离相关 warning，当前 Debug build 未失败；后续 Swift 6 严格化前应单独收口。
- `LedgerCloudKitSyncAdapter` 仍有 CloudKit deprecated block API warning 和 `CKError.Code` switch exhaustive warning。
- Mac Catalyst build 提示 MediaPipe xcframework 没有 Catalyst slice；当前 Mac 发布路径不依赖本地 Gemma / MediaPipe 推理，返回码为 0。

## 5. CloudKit 发布门禁

- `LedgerTransaction` 仍是正式账本同步 record type。
- `LedgerDashboardSnapshot` 是 tvOS / visionOS 只读展示快照 record type。
- 发布前需要在 CloudKit Console 确认 Development schema 已部署到 Production。
- tvOS / visionOS 如果纳入本版 TestFlight / ASC，需要确认对应 App ID / provisioning profile 包含 `iCloud.top.darkrio326.AutoLedger`。

## 6. Go / No-Go

当前命令级结论：GO。

- tvOS / visionOS 平台素材或 Review Notes 未准备好但在 ASC 中勾选了对应平台。
