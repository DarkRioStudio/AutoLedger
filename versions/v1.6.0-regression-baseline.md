## 1. 范围

本 baseline 用于 `GOAL-1770` 发布 smoke 收口，覆盖代码侧命令级门禁和人工发布门禁。

`v1.6.0` 的主发布线仍是 iPhone / iPad / Apple Watch / Mac Catalyst。tvOS / visionOS 已有第一版只读展示代码，并随 ASC 1.5.0 构建链路进入验证；visionOS 真机因当前无设备保留为非阻塞观察项。

## 3. 已知 Warning

- `AppFormatters`、App Intent logger、部分 Intent / OCR / CloudKit 调用存在 Swift 6 / deprecated warning。
- `VoiceLedgerIntent` / `QuickLedgerIntent` 有 MainActor 隔离相关 warning，当前 Debug build 未失败；后续 Swift 6 严格化前应单独收口。
- `LedgerCloudKitSyncAdapter` 仍有 CloudKit deprecated block API warning 和 `CKError.Code` switch exhaustive warning。
- Mac Catalyst build 提示 MediaPipe xcframework 没有 Catalyst slice；当前 Mac 发布路径不依赖本地 Gemma / MediaPipe 推理，返回码为 0。

## 5. CloudKit 发布门禁

- `LedgerTransaction` 仍是正式账本同步 record type。
- `LedgerDashboardSnapshot` 是 tvOS / visionOS 只读展示快照 record type。
- CloudKit Console schema 已发布。
- tvOS / visionOS 已随 ASC 构建链路验证；后续更换 signing 或 capability 时需重新确认 provisioning profile 包含 `iCloud.top.darkrio326.AutoLedger`。
