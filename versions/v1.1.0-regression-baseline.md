## 4. 判定口径

- 构建失败：不通过
- v1.0.0 主路径/多渠道/解析回归异常：不通过
- 去重增强（Jaccard）行为异常：不通过
- 订阅识别核心场景失败：不通过
- 分类学习不生效：不通过
- 用户反馈无法导出日志：不通过
- 服务端 Issue 自动化不工作：建议修复但不阻断（不影响 App 核心功能）

## 5. 已知限制（非阻断）

- Foundation Models 在国行设备不可用
- `MFMailComposeViewController` 在模拟器不可用，需真机测试邮件发送
- 订阅检测算法对不规则扣费间隔可能误判
- Jaccard 相似度基于 bigram，极短文本（<10字符）可能产生误判
- 服务端 Issue 自动化依赖 Gmail IMAP / Cloudflare / GitHub API，任一故障中断不影响 App
