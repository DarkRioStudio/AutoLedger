## 后续版本共同边界

2026-10-23 Owner 明确：AutoLedger 之后不再扩张产品边界。新版本只允许修复缺陷、完善现有功能、提高体验，以及完成已经进入路线图的能力。既定范围以 [路线图基线](../docs/ROADMAP.md#product-scope-policy) 为准；本计划中的后续候选均来自该基线，不新增产品方向。

本轮 P0 属于缺陷修复与体验提升。后续规则中心、Saved Views、订阅省钱看板及既定语言能力只在原有范围内完成；候选可以分批、延后或取消，不能附带扩张业务场景。修复版本无需为版本号增加功能或语言。

2026-10-23 Owner 要求修复数据管理页同步状态显示本地化键、首页待处理多位数字溢出，并推进新版本号。此前仓库已有 v1.8.0 计划，v1.9.0 只有路线图方向；本文件补齐独立计划。

本版本先完成下述 P0 显示修复；2026-10-24 Owner 追加现有匿名数据暴露的稳定性、性能和统计问题，范围见诊断修复小节。后续功能仍需按业务目标逐轮实施，不能用版本号推进冒充功能完成。

## 后续功能候选：Understand & Save

沿用路线图既有方向，本轮不承诺已实现或全部进入 1.8.0 商店首个候选：

1. 规则中心：集中解释现有规则及其作用范围，支持可预览、可撤销的调整。
2. Saved Views：保存常用筛选和搜索，复用现有账本筛选语义。
3. 订阅省钱看板：围绕已有订阅与异常事实帮助用户复核，不推测实际节省或代替用户取消订阅。
4. 国际化：提升日语质量；德语 de、法语 fr 按既有跨版本语言路线逐项评审，需翻译、识别样本、商店资料与人工验收证据后才能声明 Ready。
5. 承接已知质量缺口：英语五市场、双设备 CloudKit 往返和大账本设备性能保留未完成状态；参见 [v1.8.0 开发收口](v1.8.0-development-completion.md) 与 [性能及缺口核查](v1.8.0-performance-and-gap-audit.md)。
