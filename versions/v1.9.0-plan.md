## 后续版本共同边界

2026-10-23 Owner 明确：AutoLedger 之后不再扩张产品边界。新版本只允许修复缺陷、完善现有功能、提高体验，以及完成已经进入路线图的能力。既定范围以 [路线图基线](../docs/ROADMAP.md#product-scope-policy) 为准；本计划中的后续候选均来自该基线，不新增产品方向。

本轮 P0 属于缺陷修复与体验提升。后续规则中心、Saved Views、订阅省钱看板及既定语言能力只在原有范围内完成；候选可以分批、延后或取消，不能附带扩张业务场景。修复版本无需为版本号增加功能或语言。

## 当前边界

2026-10-23 Owner 要求修复数据管理页同步状态显示本地化键、首页待处理多位数字溢出，并推进新版本号。此前仓库已有 v1.8.0 计划，v1.9.0 只有路线图方向；本文件补齐独立计划。

Apple 美国区公开接口已回读商店 1.7.0（2026-09-23 发布），ASC 分发页显示 iOS、macOS、tvOS、visionOS 的 1.7.0 均可分发，iOS 绑定 build 132。它们是上一版证据，不代表 1.8.0 已构建、已审核或已发布。

本轮执行范围限于下述 P0 显示修复、工程版本与计划。后续功能仍需按业务目标逐轮实施，不能用版本号推进冒充功能完成。

本轮不改同步冲突判定、上传/下载、用户账本、数据库 schema、权限或收费规则。CURRENT_PROJECT_VERSION 继续由既有构建流程管理，不把本地占位 build 1 当作新 TestFlight build。

## 后续功能候选：Understand & Save

沿用路线图既有方向，本轮不承诺已实现或全部进入 1.8.0 商店首个候选：

1. 规则中心：集中解释现有规则及其作用范围，支持可预览、可撤销的调整。
2. Saved Views：保存常用筛选和搜索，复用现有账本筛选语义。
3. 订阅省钱看板：围绕已有订阅与异常事实帮助用户复核，不推测实际节省或代替用户取消订阅。
4. 国际化：提升日语质量；德语 de、法语 fr 按既有跨版本语言路线逐项评审，需翻译、识别样本、商店资料与人工验收证据后才能声明 Ready。
5. 承接已知质量缺口：英语五市场、双设备 CloudKit 往返和大账本设备性能保留未完成状态；参见 [v1.8.0 开发收口](v1.8.0-development-completion.md) 与 [性能及缺口核查](v1.8.0-performance-and-gap-audit.md)。

## 版本与发布门禁

| 项目 | 本轮目标与证据要求 |
|---|---|
| 内部开发版本 | v1.9.0 |
| App Store / MARKETING_VERSION | 1.8.0 |
| Build number | 由实际构建回读；不人工重置云端递增序列 |
| 商店版本草稿 | 核查并准备四平台 1.8.0；草稿不等于提交审核 |
| 发布说明 / 截图 | 只描述实际进入候选且验证过的能力；候选冻结时再同步 |
| Xcode Cloud / TestFlight | 需独立记录源码 SHA、Archive、build number、processing 与设备结果 |
| 正式提交 / 发布 | 本轮未执行；满足候选与材料门禁后再进入发布流程 |

本机当前只有 Command Line Tools，未安装完整 Xcode。SwiftUI 组件渲染与 Foundation 离线回归可验证本轮逻辑；GitHub Xcode workflow 仅构建 AutoLedgerCore，不替代主 App Archive。不得据此声称 iOS binary 已通过构建或设备验收。
