## 5. 判定口径

- 构建失败：不通过
- 离线回归失败：不通过
- JSON 导出/导入导致账单、订阅、自定义配置或软删除丢失：不通过
- 导入非法备份后改变本地数据：不通过
- 空库启动静默覆盖本地数据：不通过
- iCloud unavailable 时 App 崩溃：不通过；应显示错误
- iCloud capability 未配置导致无法写入：不阻断手动 JSON 版，但阻断“iCloud 自动备份”完整发布

## 6. 已知限制

- iCloud 写入依赖 `iCloud.top.darkrio326.AutoLedger` 容器，需要在 Apple Developer 后台开启并与 provisioning profile 匹配。
- 本版是单文件备份/覆盖恢复，不做 CloudKit 实时同步或多设备双向合并。
- 手动导入采用覆盖恢复，用户需要二次确认。
- 备份不包含原始截图、OCR 全文、Debug 诊断包、反馈附件或 Gemma 模型文件。
