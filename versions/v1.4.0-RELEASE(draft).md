# v1.4.0 / v1.4.x Release Notes（草稿）

更新日期：2026-05-28

## 1. 发布定位

- 内部开发线：v1.4.x
- 对外 App Store 版本：v1.3.0（沿用 `versions/v1.4.0-plan.md` 的版本号策略）
- 承接版本：v1.3.5
- 迭代记录：ITER-066 ~ ITER-090
- 当前状态：代码侧核心能力已完成并通过构建 / 离线回归；用户可见主路径的简体中文、繁体中文、英文 UI 文案已补齐；Watch App 图标已改为小尺寸优化版并补齐完整 watchOS icon set；主路径辅助功能继续补强到报表可读、状态非颜色化、减动和大字号更友好；商户别名已统一到新入账保存前生效；Support Developer 三个 consumable IAP 已在 App Store Connect 创建，代码侧具备 StoreKit 2 拉取 / 购买 / 校验 / finish / Transaction.updates 链路，等待新 TestFlight 构建后的沙盒购买点验。Debug / 调试导出文本仍保留中文。

v1.4.x 的产品主题是“更容易随手记一笔”：把 iPhone 截图记账之外的 Watch、快捷指令、语音、月报查看和历史账单整理能力收口到一个可测试版本，并提供一个不影响免费功能边界的自愿支持入口。

## 2. 当前已实现功能

### 2.1 Apple Watch 伴侣 App

- 新增 Watch App 基础入口，可查看今日支出与最近账单。
- 支持 Watch 快速记账：选择分类、输入金额、可选商户后同步到 iPhone 主账本。
- 支持 Watch 语音记账确认流：点击“语音输入”打开 watchOS 系统听写 / 文本输入，完成后自动解析为金额、商户、分类并进入确认保存页；解析失败时保留识别文本供用户修改后重新解析。
- 新增 WatchConnectivity 链路：Watch 端提交的快速记账和语音记账请求会在本地暂存，iPhone 可达时同步到 iPhone 侧 `LedgerStore` 入库并刷新账本。
- Watch App 图标已从复用 iPhone 复杂图标改为 Apple Watch 小尺寸优化版，保留白色钱包、金币、闪电、蓝绿渐变等品牌识别，并补齐 notification / settings / launcher / quick look / marketing icon slots。
- Watch 端定位为轻量入口，不独立管理完整账本，不引入云端账户或服务器同步。

### 2.2 辅助功能

- iPhone 端已覆盖账本、导入收件箱、关键指标卡片等主路径 VoiceOver 标注。
- iPhone 导入收件箱已适配 Reduce Motion，减少动态效果依赖。
- iPhone 月报页新增报表摘要、分类图、趋势图、Top 商户的 VoiceOver 文本摘要；月份切换、趋势选中和分类筛选会在 Reduce Motion 下跳过动画。
- 分类占比和 Watch 分类选择已增加勾选符号 / 选中 trait，减少“只靠颜色”表达状态；报表图表弱化态会随增强对比度设置提高可见度。
- Watch 端主列表、快速记账、语音录入、确认保存页面已补充 VoiceOver 标签、选中态和按钮提示。
- Watch 快速记账和语音确认页的分类网格已减少固定小字号，改用动态字体并保留可见选中符号。
- 目前完成的是主要交互路径可读性与可操作性，不等同于完整辅助功能审核完成；仍需真机 VoiceOver / 大字号 200% / Switch Control / 语音控制点验。

### 2.3 Shortcuts / App Intents

- 新增 `AddTransactionIntent`：通过快捷指令手动新增一笔账单，直接写入本地 SQLite，并刷新 Widget。
- 新增 `ParseLedgerTextIntent`：输入账单文本后调用本地解析器，返回结构化摘要。
- 新增 `OpenQuickAddIntent`：从快捷指令打开 App 内快速记账入口。
- 三个 Intent 已注册到 `AutoLedgerShortcuts`，与既有截图 / 语音入口并存。

### 2.4 月报历史月份浏览

- 月报页支持按月份前后翻页查看历史数据。
- 分类占比、Top 商户、6 个月趋势会随选中月份重新计算。
- 异常消费提醒仅保留在当前月，查看历史月份时自动隐藏，避免误导。
- 切换月份时会清空当前分类选中状态，减少跨月筛选残留。

### 2.5 解析与分类质量修复

- 修复微信支付详情页缺少“商户全称”时，把 `• 交易详情` 误识别为商户的问题。
- 新增拼多多“先用后付”详情页 Golden Case，覆盖金额、商户、分类、来源。
- `拼多多` 已归入购物分类。
- 同步修复既有“羊汤 / 羊肉汤”餐饮分类残留。

### 2.6 历史账单批量整理

- 编辑单笔账单分类时，如果分类发生变化，会提示选择“仅保存本笔”或“刷新全部同商户账单分类”。
- `LedgerStore.updateTransaction` 支持按同一商户批量刷新分类，并写回 SQLite、刷新 Widget、触发自动备份。
- 设置页“商户别名”每条映射新增刷新按钮，可将所有现存账单中的原商户名更新为对应别名。
- 已配置的商户别名会在新账单保存前即时生效，覆盖 OCR 导入、手动新增、快捷指令手动记账、截图快捷记账、语音快捷记账和 Share Extension；设置页“刷新”保留用于整理已存在的历史账单。

### 2.7 设置页与版本状态

- 设置页“当前版本”正文已同步到当前候选能力：Apple Watch 轻量记账、快捷指令与语音记账、月报历史月份、iCloud 备份恢复、商户别名与分类批量整理。
- 设置页“后续计划”改为面向用户的产品路线表达，包含更多支付场景识别优化、更多专业版功能和更灵活的账单整理能力。
- 版本号继续读取 App bundle 的 `CFBundleShortVersionString`，不在设置页单独写死内部 v1.4.x 版本。

### 2.8 Support Developer 可选支持入口

- 设置页新增“支持 AutoLedger”入口，进入后展示 Coffee / Lunch / Sponsor 三个自愿支持档位。
- 三个支持档位均为 StoreKit 2 consumable IAP，只表示支持独立开发，不解锁额外功能，不改变现有免费功能边界。
- 购买链路已处理 verified / unverified / pending / userCancelled，并监听 `Transaction.updates`，避免漏处理延迟完成交易。
- 购买成功后本地记录支持次数、最近支持档位和最近支持时间，仅用于 UI 感谢状态展示。
- 已新增本地 StoreKit 配置 `AutoLedgerSupport.storekit` 和 `docs/iap-support.md`，用于本地测试与 App Store Connect 配置说明。
- 3 个 consumable IAP 已在 App Store Connect 创建；首次 IAP 仍需要随新的 App 版本一起提交审核，并在新 TestFlight 构建中完成沙盒购买点验。

### 2.9 发布资产与 Watch 图标

- Apple Watch 图标已按小尺寸场景重绘：钱包轮廓保留但减少高光、阴影和内部细节；闪电加粗作为主视觉；金币仅作为半露辅助元素；去除星星、小圆点和复杂装饰。
- `AutoLedgerWatch Watch App/Assets.xcassets/AppIcon.appiconset` 已从单张 1024 universal 图扩展为完整 watchOS app icon set。
- 已输出 1024、128、64、48 小尺寸预览，便于 TestFlight / App Store 视觉检查。
- iPhone 主 App 图标未改动，Watch 图标与 iPhone 图标保持同一套品牌识别。
- App Store 截图管线已支持简体中文、繁体中文、英文三套配置；本版本计划上传简体中文与英文截图，繁体中文截图暂不上架，繁体用户仍可使用 App 内完整 UI 本地化。
- 截图预览入口已挂到根目录 README：`tools/appstore-screenshots/output/preview.html`。

## 5. TestFlight RN 建议文案

本次更新让 AutoLedger 更容易随手记一笔：

- 新增 Apple Watch 伴侣体验，可在手表上查看今日支出、最近账单，并快速记录支出。
- 新增 Watch 语音记账与快速记账：语音输入完成后可确认保存；未连接 iPhone 时会先暂存，恢复连接后同步到 iPhone 本地账本。
- 新增快捷指令动作：手动记账、解析账单文字、打开快速记账。
- 月报支持查看历史月份，趋势、分类和商户排行会随月份切换。
- 优化 VoiceOver、Reduce Motion、大字号和非颜色区分体验。
- 补齐简体中文、繁体中文、英文主路径 UI 文案，并优化 Apple Watch 小尺寸图标；本次 App Store 截图资产先准备简体中文与英文，繁体中文 UI 支持随 App 一起提供。
- 优化微信支付详情页解析，修复部分商户名识别为页面标题的问题。
- 编辑分类和商户别名时，支持批量刷新历史账单；已配置商户别名也会在新账单保存前自动套用。
- 新增可选“支持 AutoLedger”入口，可通过一次性支持帮助后续开发；支持不会解锁额外功能，核心功能继续免费。

## 6. 测试重点

1. Apple Watch：今日支出、最近账单、快速记账、语音输入、确认保存、断开 iPhone 后本地暂存、恢复连接后同步。
2. iPhone 账本：编辑分类后选择“仅保存本笔 / 刷新全部”是否符合预期。
3. 设置页商户别名：单条别名刷新是否只影响对应原商户名；配置别名后新增账单是否直接保存为别名。
4. 月报：历史月份翻页、6 个月趋势、历史月异常提醒隐藏。
5. Shortcuts：手动记账、解析账单文字、打开快速记账。
6. 辅助功能：VoiceOver、Reduce Motion、大字号 200%、非颜色区分、增强对比度、Watch 端按钮可读性。
7. 解析回归：微信支付 / 拼多多先用后付详情页不再识别为 `• 交易详情`。
8. 发布资产：iPhone / Watch 安装后图标均显示正确；Watch 主屏、通知、Watch App 列表显示新图标；简体中文 / 英文截图上传前再按 `preview.html` 目检。
9. Support IAP：本地 StoreKit 配置下能拉取 3 个档位、显示本地化价格、完成购买、取消不显示成功、pending / unverified 有明确提示；App Store Connect 产品已创建，新 TestFlight 构建后需要完成沙盒购买点验。

## 7. 已知限制 / 发布风险

- DebugView 与调试记录导出文本仍以中文为主，不适合宣称开发者 / 回归工具完整三语本地化。
- Watch 真机端到端同步、系统听写输入、VoiceOver、大字号、语音控制和增强对比度仍需实机点验；系统听写是否完全离线取决于 watchOS / 语言包 / 设备状态。
- Watch 图标已通过 asset catalog 编译和构建产物检查，但仍需真机重新安装确认；若本机仍显示旧图标，优先排查 watchOS 图标缓存。
- Support Developer IAP 的代码链路、本地 StoreKit 配置和 App Store Connect 产品创建已完成；真实 TestFlight 沙盒购买仍需等新构建可用后点验，并随新版本提交审核。
- Support IAP 不提供功能解锁和 restore entitlement；如果未来扩展到 Pro 或订阅，需要新增 entitlement 模型，不能复用当前“支持次数”语义。
- App Store 对外版本号仍按计划保持 v1.3.0；v1.4.x 是内部开发线，RN 对外发布时需避免混淆版本号。
- 繁体中文截图本版本暂不上架；App 内繁体 UI 可用，但 App Store 资产先以简体中文 / 英文为准。

## 8. 发布结论

- 功能结论：v1.4.x 主体功能已进入可测状态。
- 本地化结论：用户可见主路径的简体中文 / 繁体中文 / 英文 UI 文案已补齐；Debug / 调试导出和内部开发者文本仍保留中文。
- 发布资产结论：Watch App 图标已完成小尺寸优化并补齐完整 watchOS icon set；iPhone 主图标未改动；简体中文 / 英文 iPhone 与 Watch 截图已重新导出，繁体中文截图本版暂不上。
- IAP 结论：Support Developer consumable IAP 已具备 StoreKit 2 代码链路、本地 StoreKit 配置、App Store Connect 产品和配置文档；真实 TestFlight 沙盒购买仍待新构建后点验。
- 建议：按本 RN 进入 Xcode Cloud 构建和 TestFlight 内测；正式对外发布前补充 Watch 真机同步、系统听写、VoiceOver、大字号、语音控制、增强对比度、Watch 图标显示和 Support IAP 沙盒购买点验。
