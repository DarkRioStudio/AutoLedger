## 3. 专项回归

### 3.1 Free / Pro 边界

- 免费基础能力必须保持可用：手动记账、单张截图识别、手动酒店水单导入、酒店历史查看、基础订阅管理、基础月报、基础 Widget / Share Extension、基础导入导出、备份恢复、历史数据查看编辑删除和 `Support Developer` 赞助入口。
- 当前 P0 Pro 自动化能力为：本地邮箱水单导入无限额度、批量候选导入、高级去重 / 数据清洗、云端专属水单收件箱。
- `AutoLedgerProAccessPolicy` 应固定 P1 / Later 能力当前不进入 P0 gate：高级搜索、订阅异常提醒、月结导出包和高级规则自动应用。
- Pro 到期后仍可查看 / 编辑历史账本、酒店消费记录、原始 PDF，并可继续使用基础导出和备份恢复。
- `Support Developer` consumable 继续是赞助线，不授予 Pro 权益。

### 3.2 StoreKit 与 Pro 页面

- `AutoLedgerSupport.storekit` 包含 `AutoLedger Pro` subscription group。
- 月付商品 ID 为 `top.darkrio326.AutoLedger.pro.monthly`，本地配置价格为 `$2.99`，周期为 `P1M`。
- 年付商品 ID 为 `top.darkrio326.AutoLedger.pro.yearly`，本地配置价格为 `$19.99`，周期为 `P1Y`。
- Pro 页面应展示月付、年付、恢复购买、管理订阅和未订阅 / 已订阅 / DEBUG override 状态。
- 文案必须说明免费基础记账、手动酒店水单导入和历史数据不会被 Pro 锁住。
- 真实 ASC 商品、真实价格、本地化商店展示和 sandbox / TestFlight 购买状态以 App Store Connect 与 StoreKit 运行环境为准，不能由本地 `.storekit` 文件替代。

### 3.3 本地邮箱水单

- 免费用户可以进入邮箱配置、查看 provider 教程、执行手动扫描并预览候选。
- 免费用户每月保留 1 次成功生成待确认酒店水单草稿的本地邮箱导入额度。
- 连接测试、扫描、候选预览和失败导入不消耗免费额度。
- Pro 用户不限制本地邮箱水单成功导入次数。
- 候选召回应排除 Xcode Cloud、TestFlight、Apple Developer、WWDC、航旅凭证、构建通知等明显非水单附件邮件。
- `Folio`、`Marriott`、`Hotel`、`账单`、`电子账单` 等主题、附件名或发件人信号应进入候选。
- 无 PDF 附件但主题命中水单关键词的邮件可作为正文水单候选，并复用正文转 PDF -> PDFKit -> 酒店水单复核链路。
- 授权码 / 应用专用密码只保存在本机 Keychain，不上传云端，不进入日志、SQLite、UserDefaults 或 CloudKit。

### 3.4 云端专属水单收件箱

- Worker 只处理投递到 `folio+<token>@getautoledger.app` 的邮件，不登录用户邮箱。
- token claim 在 production 必须经过服务端 entitlement / App Store Server API 验证；本地 StoreKit 状态只用于 UI 展示。
- dev / staging bootstrap 需要显式 `ALLOW_UNVERIFIED_TOKEN_CLAIM=true`；production 不应开启。
- `pro_inbox_tokens.status` 必须为 `active`，且 `pro_expires_at` 未过期，才允许后续候选 API / 入站邮件处理。
- 候选 API、PDF 下载、状态回写和 APNs device 登记都要求 raw inbox token。
- APNs payload 只包含隐私安全提示、candidate ID 和 deep link，不包含酒店名、金额、订单号、附件文件名或 token hash。
- App 下载云端 PDF 后仍必须通过 PDFKit 本地提取和 `HotelFolioParsePipeline` 生成待确认草稿，用户确认后才入账。

### 3.5 Pro 路线图预告

- Pro 页面可以展示高级搜索、订阅异常提醒、月结导出包和高级规则自动应用为后续路线图。
- 当前 UI 不应暗示这些能力在 `v1.6.4` 已可用。
- 进入 `v1.7.0 / ASC 1.6.0` 前，需要先冻结这些能力的 Free / Pro gate 合同。
