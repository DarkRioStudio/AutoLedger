# v1.5.0 Review Notes（草稿）

更新日期：2026-06-06

适用范围：内部开发线 `v1.5.0 / v1.5.x`，对应 App Store 对外版本 `1.4.0`

## 1. App Review 建议文案

```text
AutoLedger is a local-first personal expense capture app for iPhone, iPad, Apple Watch, and Mac Catalyst.

Key review notes:
1. The app works without creating an account.
2. iCloud sync is optional. It can be enabled from Settings -> Data Management -> iCloud Sync.
3. The app includes optional consumable in-app purchases that only support the independent developer. These purchases do not unlock features or change app functionality.
4. Screenshot parsing and receipt interpretation are designed for on-device use. Users still review parsed results before saving.
```

## 2. 中文审核说明备忘

- App 不要求注册账户。
- iCloud 同步是可选项，不开启也可正常使用本地账本。
- 内购仅为“支持开发者”的 consumable，不解锁任何功能，不影响记账、OCR、导出、备份、Apple Watch、iPad 或 Mac 使用。
- 账单识别后仍需用户确认；不是静默自动记账。

## 3. 审核路径建议

### 3.1 基础主路径

1. 打开 App
2. 进入首页 / 导入页
3. 通过截图、剪贴板或文本入口生成候选账单
4. 确认后写入正式账本
5. 在账本与月报页查看结果

### 3.2 iCloud 同步

1. 打开 `设置 -> 数据管理`
2. 找到 `iCloud 同步`
3. 手动触发一次同步或刷新

说明：
- 审核不必依赖第二台设备完成跨端验证
- 若审核设备未登录 iCloud 或权限受限，App 主功能仍可正常使用

### 3.3 支持开发者 IAP

1. 打开 `设置 -> 支持 AutoLedger`
2. 页面应显示 3 个支持档位
3. 任一档位均为可选支持型 consumable

说明：
- 不购买不会影响任何功能
- 不存在 Pro 解锁、订阅墙或外部支付引导

## 4. 审核边界说明

- `Apple Watch`、`iPad` 和 `Mac Catalyst` 都是当前发布线的一部分
- `tvOS / visionOS` 本版本不提交产品能力，不应写入本次审核说明
- App Store 截图中的账单和示例内容应使用演示数据，不包含真实个人消费信息
