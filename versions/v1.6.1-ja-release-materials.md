### 4.2 App Description

```text
AutoLedger は、支払いスクリーンショット、レシート、コピーしたテキスト、ショートカット入力から個人の支出記録を作成できるローカル優先の記録アプリです。

金額、加盟店、カテゴリ、日時をできるだけ自動で読み取り、保存前にユーザーが内容を確認できます。iPhone と iPad ではすばやく取り込み、確認、編集、月次レポートの閲覧ができます。Apple Watch では手首からすばやく記録し、Mac では大きな画面で台帳を整理できます。

iCloud 同期は任意です。オンにすると、構造化された台帳データをユーザー自身の Apple デバイス間で同期できます。元の支払いスクリーンショット、レシート画像、OCR 全文、調査用ログは台帳同期の対象ではありません。

外部補助認識は既定でオフです。ユーザーが有効にする場合は自分の API Key を使用し、最小化および脱敏されたテキストのみを商店名、カテゴリ、サブスクリプション候補の補助に利用します。保存する金額、日付、正式な記録作成はユーザー確認を前提とします。
```

## 6. Review Notes 境界说明

App Review Notes 英文草稿中如包含 `v1.6.1` 功能，应使用以下边界：

```text
AutoLedger is a local-first personal expense capture app. Users can create and review structured expense records from screenshots, receipts, clipboard text, Shortcuts input, manual entry, and supported document import flows.

The hotel folio flow, when included in this build, starts from user-selected local PDF files. The app extracts text locally, sends only minimized and sanitized text to the configured recognition pipeline when external assist is enabled, and always shows a review screen before creating a hotel stay record or linked expense transaction.

The app does not automatically scan the user's mailbox in the public main flow, does not upload email credentials, and does not create official ledger records without user confirmation. Future local IMAP and cloud Worker automation are documented roadmap items and should not be described as generally available unless they are explicitly enabled in the submitted build.
```

审核员测试建议：

- 提供 Demo Mode 或示例 PDF，避免审核员必须登录真实邮箱。
- 如本构建未开放酒店 PDF 入口，不在 Review Notes 中声称可用。
- 如 tvOS / visionOS 随 ASC `1.5.0` 提交，继续说明它们是只读看板，不导入、不编辑、不删除。
