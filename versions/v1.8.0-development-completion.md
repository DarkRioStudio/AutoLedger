- Hotel Folio Inbox quota SQL 在真实 SQLite 上验证限额、跨日与不同权益隔离；Common API Dashboard 定向用例及两服务 TypeScript 检查。

## 发布边界

目标商店版本仍为 **1.7.0**，内部开发线仍为 **v1.8.0**，不改变签名、权益产品、构建号或旧产品标签。合并后使用既有 `xcbuild-v1.8.0` 触发候选构建。

客户端继续兼容当前线上清洗接口；服务端配额和 Dashboard 统计展示可独立部署，不是 App 性能修复的运行前提。Worker 部署前必须先在对应环境应用迁移 0004；本轮不部署 Worker、不运行生产迁移、不修改 Studio / Gate。

未修改部分不重复验收；新代码的真实双设备、20,000 条 UI 和商店 processing 仍是独立外部证据，不将源码通过写成这些结果已通过。App Store 提交 / 公开发布不在本轮开发操作内。

回滚：回退本轮源码；月结与扩展决策是现有 JSON 的新增可选字段，旧版本可忽略；配额表可保留，不需要删除任何生产数据。
