## 4. 判定口径

- 构建失败：不通过
- 主路径异常：不通过
- 多渠道导入任一通道不可用：不通过
- 解析关键场景（微信/支付宝/Apple）失败：不通过
- 去重窗口行为异常：不通过

## 5. 已知限制（非阻断）

- Foundation Models（Apple Intelligence 本地大模型）在国行设备不可用，`SmartReceiptParser` 始终走纯规则路径
- 商户别名仅存 UserDefaults，不随 iCloud 同步
- 微信详情页标签块解析依赖标签连续性，极端布局可能需后续调整
