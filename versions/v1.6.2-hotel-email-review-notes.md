## 1. 审核入口

酒店邮箱水单导入是用户主动触发的本机功能。审核员不需要登录真实邮箱即可验证主流程，可以使用 App 内置 Demo Mode：

1. 打开 AutoLedger。
2. 进入“酒店消费”。
3. 点击右上角 `+`。
4. 选择“邮箱水单导入”。
5. 在 `Demo Mode` 区域点击“加载示例水单”。
6. 在“候选水单邮件”中选择 `autoledger-demo-hotel-folio.pdf`。
7. App 打开酒店水单复核页，展示虚构酒店、入住日期、金额、来源邮件和原始文本。
8. 审核员可以编辑字段，点击确认后生成一条酒店消费记录和一条关联普通支出流水。

## 2. Demo 数据边界

- Demo 使用虚构酒店 `Demo Bay Hotel`、虚构订单号 `DEMO-2026-0618` 和虚构邮箱域名 `example.test`。
- Demo PDF 在本机生成，不从网络下载，不连接 IMAP，不读取 Keychain 授权码。
- Demo 文本只包含示例金额、房晚、税费、服务费和遮蔽卡号 `**** 4242`，不包含真实会员号、证件号、手机号、银行卡号或真实邮箱。
- Demo 结果和真实邮箱导入一样进入待确认复核链路，不会自动正式入账。

## 3. 隐私说明

- 真实邮箱扫描必须由用户点击“扫描邮箱水单”主动触发。
- 邮箱授权码只保存在本机 Keychain，不上传云端，不写入 SQLite、UserDefaults、CloudKit 或日志。
- App 不上传完整邮箱内容；只对用户选择的候选 PDF 附件提取必要文本，并在模型识别前尽量脱敏。
- 所有识别结果默认进入待确认状态，用户确认后才正式写入账本。
- 用户可以删除待确认草稿和正式酒店消费记录。

## 4. 公共版本开关策略

- `HotelFolioEmailDemoMode.isAvailable` 是 App 内 Demo Mode 的集中开关，公共版本默认保留，方便审核和用户无邮箱演示。
- Demo Mode 只生成虚构候选邮件，不开启后台扫描、不连接真实邮箱、不读取授权码。
- 真实 IMAP 扫描仍保持用户主动点击，不做后台自动读取。
- Worker 云端自动化和持续邮箱扫描不属于本版本公共主链路。
