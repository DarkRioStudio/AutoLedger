# v1.2.0 版本计划

更新日期：2026-04-13
文档状态：Draft（待用户评审）

## 1. 版本定位

- 版本号：v1.2.0
- 承接版本：v1.1.0
- 版本主题：分析洞察 + 平台扩展 + 订阅优化
- 核心目标：在 v1.1.0 订阅识别 + 用户反馈闭环基础上，向上游扩展"消费洞察层"——增强月报分析（环比趋势、分类图表、异常消费检测），向外扩展"平台覆盖层"——支持云闪付 / 银联闪付两大新支付平台，向下优化"订阅管理层"——订阅年度总览、费用优化建议；同时承接 v1.1.0 TestFlight 外测反馈的高优紧急修复。

## 3. In Scope / Out of Scope

### In Scope

**Phase 1 — 月报分析增强**
- 报告页（`ReportView`）改版：
  - 月度消费总览卡（总支出金额、记账笔数、TOP1 商户）
  - 分类占比图：Swift Charts 环形图（Pie/Donut），展示各分类支出比例
  - 月度趋势柱图（Swift Charts Bar Chart）：近 6 个月支出环比
  - TOP5 商户排行（按月累计消费额降序）
- 异常消费检测：
  - 当月某分类支出若超过近 3 个月该分类月均值的 150%，则在报告页顶部展示"🔔 本月 [分类] 支出较近期偏高"提示卡
  - 异常阈值默认 150%，可在设置页"消费分析"中调整（100%～300% 范围）
  - 检测逻辑由 `MonthlyInsightService`（新建）承担，输入 `MonthlySnapshot`，输出 `AnomalyAlert` 列表

**Phase 2 — 新支付平台适配**
- 云闪付（China UnionPay Cloud Flash Pay）：
  - 新增 `ReceiptSource.unionPay`（云闪付 / 银联闪付）
  - `ReceiptParser` 新增 `parseUnionPayVoucher(lines:)`：识别"云闪付"/"银联"特征行，提取商户全称、金额（支持"¥XX.XX"与"实付¥XX.XX"两种格式）、交易时间
  - `ShareViewController.bundleSourceMap` 新增云闪付 Bundle ID（`com.unionpay.chsp`）映射
  - `SampleReceiptProvider` / `OfflineRegression` 新增云闪付回归样本（≥2 种）
- 银联线下 POS / 闪付二维码（如有真机样本，视情况同 Phase 2 一并完成）

**Phase 3 — 订阅管理增强**
- 订阅年度总览：`SubscriptionListView` 底部新增"预估年度订阅开销 ¥X,XXX.XX"统计卡
- 费用优化建议：对「月付」订阅且商户有已知年付定价时（由用户在编辑订阅时填写年付价），计算月付 vs 年付差额，在订阅详情页展示"切换年付可节省 ¥XX.XX/年"提示
- 订阅编辑：`SubscriptionEditView`（新建）支持修改商户名、方案名称、周期、金额、下次预测日期、备注；现有订阅长按 → 编辑（目前仅长按 → 删除）

**Phase 4 — 遗留修复 + 版本收口**
- `deletedTransactions` 持久化到 SQLite 软删除列（`deleted_at TIMESTAMP`，`DELETE` 改为 `UPDATE SET deleted_at = now()`；加载时过滤 `WHERE deleted_at IS NULL`；`DeletedTransactionsView` 跨会话可恢复）
- 承接 v1.1.0 TestFlight 外测反馈高优修复（视反馈内容追加，优先级高于 Phase 3）
- 回归基线更新（覆盖月报图表 / 云闪付 / 订阅管理 / 软删除新场景）
- v1.2.0 发布门禁判定

### Out of Scope（本版不做）

- 云端 AI / 远程推理
- iCloud 多设备同步
- Apple Watch 支持
- 多笔账单拆分 / 预算设定与超支预警
- 自动删除已识别截图
- 抖音本地生活（已有基础，视外测优先级）

## 4. 阶段拆分

| 阶段 | 目标 | 输出物 | 风险 |
|---|---|---|---|
| Phase 1 | 月报分析增强 + 异常消费检测 | `MonthlyInsightService`、`AnomalyAlert`、`ReportView` 改版（Swift Charts 图表）、设置页异常阈值入口 | Swift Charts 需 iOS 16+（已满足）；异常阈值调参需真实数据验证；图表渲染性能需真机测试 |

| Phase 4 | 软删除持久化 + 外测修复 + 版本收口 | SQLite `deleted_at` 列迁移、`DeletedTransactionsView` 跨会话恢复、`v1.2.0-regression-baseline.md`、`v1.2.0-RELEASE(draft).md` | SQLite 结构变更需 migration guard（`ALTER TABLE IF NOT EXISTS`）；外测反馈未知，可能引入范围变更 |

## 7. 验收与回滚

- **验收标准**：
  - 报告页展示月度消费总额、分类占比 Donut 图（可点击高亮）、近 6 月趋势柱图、TOP5 商户列表
  - 当月某分类消费超过近 3 月均值 150%（默认），报告页展示异常消费提示卡，提示准确无误报
  - 设置页可调整异常阈值，修改后下次进入报告页立即生效
  - 上传云闪付支付截图，商户、金额、时间均准确提取，来源标记为"云闪付"
  - 云闪付回归样本（≥2 条）离线断言全通过
  - 订阅列表底部展示"预估年度订阅开销"
  - 月付订阅编辑页可录入年付参考价，并展示节省金额建议
  - 长按订阅条目可进入编辑页修改所有字段，保存后 SQLite 同步更新
  - 删除账单后退出并重启 App，"最近删除"列表仍可见该条目，左滑可恢复
  - 永久删除后重启 App 不再出现，SQLite 中 `deleted_at` 有值
  - v1.1.0 回归基线全项无功能回退

- **回归范围**：
  - v1.1.0 回归基线全项
  - v1.2.0 新增场景：月报图表渲染 / 异常检测触发 / 云闪付识别精度 / 订阅编辑 CRUD / 软删除跨会话

- **回滚策略**：
  - Swift Charts 图表为 ReportView 局部改动，回退不影响账本核心路径
  - `parseUnionPayVoucher` 为独立方法，注释掉调用点即可回退，不影响其他 parser
  - `SubscriptionEditView` 为新增视图，删除后恢复长按仅删除行为
  - SQLite `deleted_at` 列通过 `ALTER TABLE IF NOT EXISTS` 加列，已有数据不受影响；回退版本读取时 `deleted_at` 为 NULL 视为未删除，无数据丢失风险
