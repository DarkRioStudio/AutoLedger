## Scope Boundary

本版本维护简体中文、繁体中文、英文和日语，并只新增韩语 `ko` / 韩国语言组。`v1.8.0` 改为英语五市场质量组且不新增 UI 语言；任何后续市场或语言规划都不得扩大当前 Release Candidate 的实现、截图或 ASC locale 范围。

从 ASC `1.6.0` 起，App Store Primary Language 为 `English (U.S.) / en-US`；API 回读证据已归档。Xcode 工程同时使用 `developmentRegion = en`，发布前仍需复核英语截图、App Preview 与其它语言的 fallback 关系。

## Five Release Gates And Review Evidence

每个公开支持语言以以下五项作为发布门禁：

1. **Store Visibility**：App 信息、版本信息、订阅、截图和需要公开的 App Preview 完整。
2. **UI Readability**：主 App、Watch、Widget、Control Widget、Share Extension、App Intents / Shortcuts 和截图模式主路径可读。
3. **Recognition Pack**：Core 语言包覆盖金额、日期、商户、分类、币种和实际可用的 OCR hint。
4. **Realistic Samples**：脱敏或高拟真的支付、小票、订阅和酒店样本进入 golden / offline regression。
5. **Regional Coverage**：当地币种、日期、税费、折扣、服务费、支付方式和酒店字段有专项回归。
母语或合格人工审校继续作为第六列质量证据记录，但不是 ASC `1.6.0` 的硬发布门禁。缺少审校时必须写明机器检查、工程视觉复核、线上资产回读和已知用词风险，不能把未取得的母语结论标为 Ready。

只有五项发布门禁均有当前证据时才能标记 Ready。已有公开语言的遗留地区缺口必须写实，不得用 UI 已翻译替代完整支持结论。

## Status Definitions

| 状态 | 含义 |
|---|---|
| Ready | 五项发布门禁均有当前版本证据，可公开维护；人工审校状态另行写实 |
| Build | 属于本版本范围，仍在补实现或发布资产 |
| Audit | 可执行基础已存在，仍缺样本、地区专项或人工审校 |
| Scheduled | 已绑定后续明确版本，不属于当前实现范围 |
| Candidate | 尚未绑定正式版本或仍需复杂度评估 |
| Later | 当前不排期 |

## English Primary Language Gate

- 当前值：App Store Connect `English (U.S.) / en-US`，已通过 API 回读确认。
- 工程证据：`AutoLedger.xcodeproj` 的 `developmentRegion = en`；它只证明二进制默认开发区域。
- 发布复核：确认全平台英语截图、五语 iPhone App Preview、App Info、订阅与其它语言 fallback 在 `en-US` 主语言下符合预期。
- 线上证据：继续保留 ASC audit 回读；仓库 `metadata.yml` 只是真源配置，不能单独替代线上证据。
- 回滚：若后续发现主语言 fallback 或资产映射错误，在 ASC 按平台修正；不能通过改 Xcode 文案伪造线上完成状态。

- ASC metadata、截图与 App Preview 已完成 API 回读；显式 `en-GB` 元数据和六平台截图已与当前 `en-US` 对齐，提交前执行最终幂等 audit。

- 五语截图和 iPhone App Preview v003 已上传并通过 MD5 / 处理状态回读；五语 poster frame 已统一为 `1.4s / 00:00:01:12` 并确认生成图 `COMPLETE`。
- 在 release-readiness 中逐项记录五项门禁和 Human Review 证据；不以构建成功替代商店、语言或样本证据。

## Admission Rules

- 不能只因 `Localizable.strings` 有翻译就宣称支持。
- Vision OCR hint 必须基于运行时实际支持列表；不支持时回退通用规则和用户确认。
- 识别包属于免费基础能力，不按语言做 Pro gate。
- 样本不能包含真实姓名、邮箱、订单号、卡号、酒店确认号、个人地址、可扫描二维码或 token。
- 新语言未 Ready 时原则上不能写入公开支持清单；若版本负责人明确接受已记录的非安全性质量缺口，可标为 Release Candidate，但不得伪造 Ready 证据。
- 后续语言顺序只由跨版本语言路线调整，本矩阵不能独立扩大 `v1.7.0` 范围。

## Non-Goals

- 不在 `v1.7.0` 加入西语、巴葡或其它第六种 UI 语言。
- 不维护全量世界城市库。
- 不远程热更新账单识别规则或语言包。
- 不自动上传用户真实票据、OCR 原文或纠错数据。
- 不把地区票据优化描述为税务、报销或金融合规。
