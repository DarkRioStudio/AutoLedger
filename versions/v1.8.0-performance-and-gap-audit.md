## 首批性能范围

用户反馈：几百条账单时点击明显卡顿。源码发现列表金额 / 日期显示与无障碍描述重复格式化；每次调用创建 Foundation formatter。导航选中状态又会使列表重新求值，关键词 / 高级搜索及月份筛选可重新扫描账本。

本轮处理：

- 缓存金额与展示日期 formatter，按地区、币种、日期模板和当前时区 / calendar 区分；锁内使用实例，避免后台调用与 UI 相互修改；容量有界，不保存账单内容。
- 同一账单行的可见文字和无障碍描述复用金额 / 日期文本。
- LedgerStore 复用最后一次列表查询结果；交易 revision、当前账本、查询、时间范围和地区设置变化时失效。无搜索的全账本路径仍直接使用现有可见交易快照。
- 不改变存储、CloudKit、金额、币种所有权、排序、Pro gate 或用户数据。

验收包括并发地区格式一致性、零小数币种、缓存淘汰、同 ID 编辑、删除、账本切换、筛选边界、500 / 5,000 / 20,000 条合成账本。回滚为回退本轮源码，不需数据迁移。

## 验证与证据边界

运行 `bash scripts/run_formatter_performance.sh` 可复现旧 formatter 构造与新行格式化的对照；脚本同时验证多个地区 / 币种并发结果与旧格式一致。完整离线回归输出 `PERF list`，比较首次搜索与重复读取的耗时。

这些数字是 macOS 上的合成计算基准，不是 SwiftUI 帧耗时、真实用户账本或 iPhone 点击延迟。真实设备需要沿用 `--performance-fixture-count 500|5000|20000`，用同一设备、同一构建配置记录账单打开、返回、筛选、滚动及待处理中心的主线程耗时 / 卡顿。不能由 formatter 加速倍率推导 App 整体加速倍率。

2026-09-22 自动验证：完整离线回归 1,158 项 PASS（含上述缓存失效和三个规模的顺序一致性），所有静态 smoke 通过；generic iOS workspace 无签名构建通过。Swift 6 strict-concurrency 编译、2,000 次并发地区格式对照及多币种淘汰验证通过。

## 2026-09-22 真机反馈与第二批

第一批合并源码 `12b91a7278ac8faeb087eea297cf1d7ac52b4a71` 以 Debug / 1.7.0 (1) 原位安装到 iPhone 15 Pro（iOS 27.0）。Owner 对 500 条隔离账单反馈“还行”，切回真实账本后明确反馈“真实账本也流畅”。这不是商店构建，也不是旧构建与新构建的控制变量比较。

Time Profiler 前测：500 条隔离数据记录 61.32 秒，标记 9 次 >250 ms 停顿，最长 508.48 ms；正常真实账本记录 46.31 秒，标记 3 次，最长 1,045.59 ms。真实账本主线程 CPU 采样中 `InboxView.shortcutTransactions` 的 inclusive 样本累计约 808 ms，`AppLanguagePreference.localizedStrings` 约 785 ms。两者属于同一调用链，不能相加或视为单次点击延迟；底层反复创建语言 Bundle，发生在每条交易的过滤闭包内。

第二批 `ITER-467` 复用全部语言备注集合，并只在交易 / 账本范围 revision 或候选集合变化时重算快捷记账数量；不构造匹配交易数组。同步修复数据清洗页内容大标题与系统大导航标题重复。完整离线回归 1,171 项 PASS；真机签名构建、原位安装已通过。

离线快捷记账数量基准（不等同真机 UI 延迟）：

| 条数 | 首次统计 | 1,000 次重复读取平均 |
|---|---:|---:|
| 500 | 0.152 ms | 0.000145 ms |
| 5,000 | 1.447 ms | 0.000145 ms |
| 20,000 | 10.860 ms | 0.000150 ms |

真机复测：同一台 iPhone、Debug 配置、真实账本，记录 60 秒，Owner 反馈“还可以”。本次采样已不再出现旧 shortcutTransactions / localizedStrings 热点；InboxView.body inclusive 样本约 64 ms（前次约 825 ms）。两轮交互路径和持续时间不同，不能把该差值换算成 App 加速倍率。本轮仍有 8 次 >250 ms 的仪器停顿，最长约 675.32 ms；仍需后续针对列表布局、详情页等路径分析，不能声称所有页面零卡顿。原始 trace 留在本机，不上传真实账本内容。
