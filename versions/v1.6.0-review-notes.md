# ASC 1.6.0 Review Notes

## 1. 当前结论

- Review Notes 使用两个英文 profile：`main` 用于 iOS / macOS，`readonly` 用于 tvOS / visionOS。
- 四个平台均不需要 demo account；审核员可以不提供真实邮箱凭据，使用免费手动记账与酒店 PDF 导入验证主链路。
- iPhone / iPad / Mac 的说明覆盖免费主路径、AutoLedger Pro、专属水单收件箱、本地邮箱扫描、确认后入账和匿名发布观测。
- tvOS / visionOS 单独说明为只读看板；没有同 Apple ID 的 iCloud 快照时，设计空状态也是有效审核结果。
- 韩语母语审校暂时缺少合适审校者。根据当前发布决定，它不再阻断 ASC `1.6.0`；机器检查、工程视觉复核、线上资产回读和用户确认仍保留，母语反馈转为发布后修订来源。

## 2. 审核路径

### iPhone / iPad / Mac

1. 打开 AutoLedger；无需账号或订阅即可测试手动记账、单张截图 / 照片识别、语音 / 文本记账、历史编辑、月报和基础导入导出。
2. 所有识别结果先进入确认流程，不会静默写入正式账本。
3. 进入“酒店消费”，点击 `+`，选择手动 PDF 导入；提取结果进入酒店水单复核，用户确认后才保存。
4. 进入“设置 -> AutoLedger Pro”，查看月付 / 年付、恢复购买、管理订阅和免费 / Pro 边界；需要测试 Pro 时使用 App Store sandbox purchase flow。
5. Pro 生效后可在“酒店消费 -> + -> 云端收件箱”领取专属地址。服务只处理用户主动转发到该地址的水单，不登录或扫描用户私人邮箱；下载后的候选仍需在 App 本地复核。
6. 本地邮箱扫描是另一条用户主动触发路径，授权码只保存到本机 Keychain。审核员无需提供真实邮箱，可始终使用免费手动 PDF 路径。

### Apple TV / Apple Vision

1. 打开 App 查看月度概览、分类、趋势和最近记录。
2. 同一 Apple ID 已有 AutoLedger iCloud 私有数据库快照时，可展示结构化只读数据；否则展示设计空状态。
3. 这两个 target 不导入截图 / PDF / 邮箱，不编辑或删除账本，不设置 Pro 自动化，也不会创建交易。

## 3. Free / Pro 边界

免费能力持续包含：

- 手动记账、单张截图 / 照片识别、语音 / 文本输入；
- 手动酒店水单 PDF 导入与酒店历史查看；
- 历史账单查看、编辑和删除；
- 基础月报、基础导入导出、备份恢复、Widget 与 Share Extension。

Pro 只解锁省时间的自动化：本地邮箱水单扫描、专属收件箱、批量候选、高级搜索 / 去重、订阅异常、月结包、智能整理建议和高级规则自动应用。Pro 到期不会锁住已有历史数据或免费主路径。

## 4. 隐私对齐

Review Notes 必须与以下三处保持同一口径：

- [`AutoLedger/AutoLedger/PrivacyInfo.xcprivacy`](../AutoLedger/AutoLedger/PrivacyInfo.xcprivacy)
- ASC App Privacy nutrition label
- [线上隐私政策](https://getautoledger.app/privacy)

当前声明：Crash Data、Performance Data、Product Interaction 仅用于 Analytics，not linked，not tracking。匿名 analytics allow-list 不包含金额、商户、票据 / OCR 内容、截图、PDF、邮箱、酒店名、精确位置、Apple ID 或 StoreKit 交易标识；上报失败不影响记账。

普通 iCloud 账本同步只处理用户私有数据库中的结构化账本数据，不包含原始票据截图、OCR 原文、邮箱授权码或调试包。专属水单收件箱属于用户主动使用的独立云端路径，必须明确其短期 PDF / 候选处理边界，不能用“零上传”描述整个 App。
