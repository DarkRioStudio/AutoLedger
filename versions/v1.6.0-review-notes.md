## 1. App Review Notes - English Draft

AutoLedger is a local-first personal expense capture app for iPhone, iPad, Apple Watch, and Mac Catalyst. This version also includes optional read-only Apple TV and visionOS dashboard targets if those platforms are enabled for review.

Key review notes:

1. No account is required by default.
2. iCloud sync is optional and uses the user's private iCloud database. It is used to sync structured ledger records across the user's Apple devices.
3. Original receipt images, payment screenshots, OCR raw text, and debug logs are not uploaded as part of ledger sync.
4. Optional external AI assist is disabled by default. If the user enables it, they must provide their own API key. AutoLedger sends a minimized and sanitized OCR summary only to suggest merchant, category, and subscription hints. It does not let the external model decide the amount, transaction date, or whether to save a record.
5. Apple Watch supports quick expense entry, recent records, and watch face complications.
6. Mac Catalyst supports a larger ledger workspace for reviewing and organizing records.
7. Apple TV and visionOS, if included in this submission, are read-only dashboards. They do not import, edit, delete, or modify ledger data.
8. Any support purchase, if visible in the app, is optional and does not unlock required functionality.

Suggested reviewer flow:

1. Open the iPhone or iPad app.
2. Add a manual expense or import from mock text / clipboard.
3. Review the ledger and monthly report.
4. Open Settings to review iCloud sync and optional external assist settings.
5. If testing Apple Watch, add a quick record and confirm it appears on iPhone after sync.
6. If testing Mac Catalyst, open the ledger workspace and review the larger table layout.
7. If testing Apple TV or visionOS, open the read-only dashboard after iCloud data has been synced from the main app.

If Apple TV or visionOS are not included in the current ASC platform submission, remove note 7 from the final App Review Notes.

## 2. 中文提交备注草稿

AutoLedger 是一款本地优先的个人快速记账 App，支持 iPhone、iPad、Apple Watch 和 Mac Catalyst。本版本如果同时启用 Apple TV / visionOS 平台，它们仅作为只读账本看板展示，不会导入、编辑、删除或修改账本数据。

- Apple Watch 支持快速记账、最近账单和表盘复杂功能。
- Mac Catalyst 提供更大的账本查看和整理区域。
- Apple TV / visionOS 如果随本版本提交，仅为只读展示端。
