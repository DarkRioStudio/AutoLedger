## 5. 版本亮点

1. **订阅识别**：自动检测周期性扣费（月付/年付/周付），续期邮件截图高置信直接入库
2. **扣费提醒**：预测下次扣费日，提前 1 天本地通知，首页"即将扣费"卡片
3. **分类学习**：用户修改分类后，同商户后续交易自动使用修正分类
4. **用户反馈**：三级日志分级（L1 脱敏 / L2 增强 / L3 完整诊断），预览确认后邮件发送
5. **开发者模式**：DebugView 隐藏为版本号彩蛋，内容升级为 SQLite 浏览 + 系统信息 + 一键诊断包
6. **反馈闭环**：邮件 → Cloudflare → Gmail → GitHub Actions → 自动创建 Issue
7. **去重增强**：新增 OCR 文本 Jaccard 相似度比对，同一截图微调后仍能拦截

## 6. 回滚方案

- 触发条件：新版本导致核心记账链路不可用、数据丢失或频繁崩溃
- 回滚步骤：`git checkout v1.0.0` 恢复代码，重新构建并安装
- 影响评估：丧失订阅识别/提醒/分类学习/反馈能力，核心记账不受影响
- 数据兼容：新增 SQLite 表使用 `CREATE TABLE IF NOT EXISTS`，回退版本不会因表存在而崩溃
