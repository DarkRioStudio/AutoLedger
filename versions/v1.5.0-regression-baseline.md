# v1.5.0 回归基线

更新日期：2026-06-06

## 1. 目标

锁定 `v1.5.0` 当前发布平台收口范围，覆盖 `iPhone / iPad / Apple Watch / Mac Catalyst`、iCloud 同步基础链路、JSON / CSV / backup、可选支持型 IAP、以及当前发布平台截图导出。  
本基线明确区分 4 种验证层级：

- `PASS（命令）`：本轮已执行命令并通过
- `PASS（离线）`：由离线 / Golden 回归覆盖
- `PASS（用户点验）`：本轮开发周期中已由用户在真机或实际界面确认
- `PENDING`：仍需真机、Xcode Cloud、ASC 或人工提交前检查

## 2. 最小验证命令

```bash
xcodebuild -workspace AutoLedger/AutoLedger.xcworkspace \
  -scheme AutoLedger \
  -configuration Debug \
  -destination 'generic/platform=iOS' \
  build

xcodebuild -workspace AutoLedger/AutoLedger.xcworkspace \
  -scheme AutoLedger \
  -configuration Debug \
  -destination 'platform=macOS,variant=Mac Catalyst' \
  build

bash scripts/run_offline_regression.sh
bash scripts/run_golden_regression.sh

bash tools/appstore-screenshots/scripts/export.sh --ios-only --locale zh-Hans
bash tools/appstore-screenshots/scripts/export.sh --watch-only --locale zh-Hans
bash tools/appstore-screenshots/scripts/export.sh --ipad-only --locale zh-Hans
bash tools/appstore-screenshots/scripts/export.sh --mac-only --locale zh-Hans
```

## 6. 门禁判定口径

- 任一发布平台构建失败：不通过
- 离线回归失败：不通过
- Golden 回归失败：不通过
- iPad / Mac 截图导出失败或成品图不可用：不通过
- iCloud 同步导致正式账本丢失：不通过
- backup 恢复破坏正式账单或最近删除：不通过
- 可选支持型 IAP 错误解锁功能或阻塞主功能：不通过
- Watch 表盘金额必须点开 Watch App 才刷新：暂列发布前复测项，若持续复现则需判断是否阻断 Watch 端体验

## 7. 已知限制

- `tvOS / visionOS` 不在 `v1.5.0` 发布门禁内，本版只保留 target、设计和实现评估。
- Mac 截图导出依赖本机 Accessibility 权限与 `System Events`。
- iPad / Mac 截图使用固定 screenshot fixture，不读取真实用户账本。
- 当前 `CURRENT_PROJECT_VERSION` 仍为 `1`，TestFlight / App Store 提交前需按实际构建流水线递增 build number。
- Apple Watch 真机后台刷新链路仍需单独复测，当前不以截图导出代替真机推送证明。
