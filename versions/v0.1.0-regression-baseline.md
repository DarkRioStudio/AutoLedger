## 3. 回归矩阵

### 3.1 主路径
- 场景 0：选择真实支付截图→Vision OCR 输出文本→规则解析成功入账
- 场景 1：导入样例截图文本→规则解析金额/商户/时间→成功入账
- 场景 2：查看账单列表→最新记录展示正确
- 场景 3：编辑账单金额/分类/备注→返回列表后展示更新
- 场景 4：查看月报→总额、交易数和分类拆分与账本一致

### 3.2 协议与接口
- 场景 1：`OCRService` 能从截图中提取非空文本
- 场景 2：`ReceiptParser` 能解析 OCR 文本中的金额、商户和时间
- 场景 3：`LedgerStore` 导入和编辑后能同步更新账本和月度汇总
- 场景 4：SQLite 仓库可完成读取、新增和更新

### 3.3 异常与降级
- 场景 0：图片读取失败或 OCR 无文本时应给出状态提示，不崩溃
- 场景 1：重复导入同一示例时应避免重复记账
- 场景 2：解析失败时应用应给出状态提示，不崩溃
- 场景 3：真实 OCR 失败时仍可使用样例导入继续验证主路径
- 场景 4：SQLite 写入失败时界面应有提示，不崩溃
