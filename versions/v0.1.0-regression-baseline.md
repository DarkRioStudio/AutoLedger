# v0.1.0 回归基线

更新日期：2026-03-27

## 1. 目标

用于锁定当前版本最小稳定面，防止迭代回退。

## 2. 最小验证命令

```bash
# 构建并运行 iOS 单元测试
xcodebuild -scheme AutoLedger -configuration Release build
xcodebuild -scheme AutoLedger -configuration Debug test
```

## 3. 回归矩阵

### 3.1 主路径
- 场景 1：导入支付截图→识别金额/商户/时间→成功入账
- 场景 2：查看账单列表→编辑账单分类→保存成功

### 3.2 协议与接口
- 场景 1：OCR 服务正确返回识别结果并处理不同语言格式
- 场景 2：数据库读写接口正常，新增和查询账单一致

### 3.3 异常与降级
- 场景 1：识别失败或截图损坏时应提示用户手动补录
- 场景 2：权限被收回时应用应优雅降级，不崩溃

## 4. 判定口径

- 构建失败：不通过
- 主路径异常：不通过
- 关键回归项缺失：不通过

## 5. 回填要求

 每轮回归后记录：
 - 执行人：迭代执行人
 - 执行时间：实际执行日期
 - 执行结果：PASS/BLOCKED
 - 阻断项：描述导致回归失败的场景
 - 处理结论：解决方案或回滚计划
