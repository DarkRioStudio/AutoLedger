## 5. 版本亮点

1. **统一备份包**：`BackupBundle` v1 覆盖账单、最近删除、订阅、分类学习、自定义分类/来源、商户别名、订阅年付价/备注与低风险设置。
2. **手动迁移**：设置页新增数据管理，可导出 JSON 并从 JSON 覆盖恢复。
3. **恢复防护**：导入前校验 schema、重复 ID 与空包，覆盖恢复失败会尝试回滚。
4. **iCloud 轻量备份**：开启后将最新备份写入 iCloud Drive `AutoLedgerBackup.json`，支持立即备份与后台自动备份。
5. **重装恢复提示**：空库启动检测到 iCloud 备份时弹窗提示恢复，不静默覆盖。

## 6. 回滚方案

- 隐藏设置页"数据管理"入口即可关闭手动导入导出 UI。
- 关闭 `iCloudBackupEnabled` 可停用自动备份；已生成 JSON 文件不影响本地 SQLite 主数据库。
- 若恢复逻辑出现问题，回退 `BackupBundle` / `SQLiteTransactionStore.replaceForRestore` / `LedgerStore.restoreBackup` 相关改动。
- iCloud entitlement 若影响签名或审核，可移除 entitlement 并保留手动 JSON 导入导出能力。
