## Planning Boundary

本矩阵把 `v1.8.0` 从“新增西语 / 巴葡”调整为英语五市场质量组。它不表示任何 ASC localization、截图或价格已经修改，也不授权本轮改动 App 代码、metadata-as-code 或 StoreKit 配置。

目标市场：

- United States；
- United Kingdom；
- Canada；
- Australia；
- Singapore。

西班牙语和巴西葡语保留为日德法之后的候选，不属于 `v1.8.0`。

## Status Definitions

| 状态 | 含义 |
|---|---|
| Inherited | 从上一版本继承，必须保持不回退 |
| Scheduled | 已绑定本版本，尚无完整证据 |
| Build | 已有可执行实现，仍缺地区或商店验收 |
| Audit | 实现完成，等待人工与发布材料复核 |
| Ready | 市场门禁全部有版本内证据 |
| Blocked | 缺关键实现、测试、人工审校或线上条件 |

## Market Contract

| 市场 | App / ASC 语言 | 日期重点 | 主要币种 | 重点验收 |
|---|---|---|---|---|
| 美国 | `en` / `en-US` | MDY、12 小时制 | USD | 主语言、隐私、订阅基准价、收据税费与小费 |
| 英国 | `en`，按需要配置 `en-GB` | DMY、12 / 24 小时 | GBP | VAT、酒店水单、价格和支持术语 |
| 加拿大 | `en`，按需要配置 `en-CA` | 地区可变，禁止猜测 | CAD | GST / HST / PST、英语与未来法语边界 |
| 澳大利亚 | `en`，按需要配置 `en-AU` | DMY、12 / 24 小时 | AUD | GST、酒店与旅行收据、地区价格 |
| 新加坡 | `en`，按需要配置 `en-SG` | DMY、12 / 24 小时 | SGD | GST、多币种旅行、英语 / 中文混排票据 |

`en-US` 是默认翻译源与 ASC Primary Language。只有存在可验证差异时才新增其它英语 ASC localization；不复制完全相同内容来制造覆盖数量。

## Currency And Exchange-Rate Gate

- 账本本位币、原始币种、换算金额、汇率日期和提供方分别可见；
- JPY / KRW 等零小数币种与常见两位小数币种正确；
- 小数点、千分位、负数、退款和多币种汇总按 locale / 合同处理；
- 汇率失败或过期时保留原币和待处理状态，不静默猜测；
- 月报、分享与导出说明汇率口径，不承诺税务、会计或投资准确性。

## Store Gate

- Name、subtitle、promotional text 和描述以私密账本、自动化导入、旅行 / 酒店为主；
- 不以 `expense tracker`、`budgeting app` 或银行同步作为主定位；
- 每个市场检查关键词、截图排序、订阅价格、支持 URL 和隐私 URL；
- Pro 主要表达为 `Unlock automation`，年付区分早鸟 `$19.99` 与标准 `$24.99` 规划；
- metadata-as-code 只代表计划内容，ASC 实际值必须在有发布授权时写入并回读。

## Sample And Human Review

每个市场至少准备脱敏或高拟真样本，覆盖：

- 一般收据；
- 税费 / 服务费 / 小费；
- 一张酒店水单；
- 一项多币种旅行消费；
- 一项订阅或周期扣费；
- 一个日期歧义或地区格式用例。

样本不得包含真实姓名、邮箱、卡号、订单号、酒店确认号、地址或可扫描二维码。英语母语或当地用户需要审校商店首屏、关键 UI、订阅说明和支持内容。

## Acceptance

- `en-US` 是稳定默认翻译源与工程 fallback；
- 五个市场无 CNY / `¥` / `zh_CN` / 中文年月 / `万` 等错误默认泄漏；
- 同一笔交易在主 App、Watch、Widget、报告、分享和导出中保持币种语义一致；
- 歧义日期不以固定解析顺序静默落账；
- 每个市场的商店、格式、样本、隐私、支持和人工审校都有独立证据；
- 现有简中、繁中、日语和韩语基线不回退。

## Non-Goals

- 不在本版本新增 UI 语言；
- 不把英语内容相同视为五个市场自动 Ready；
- 不新增银行同步、复杂预算或地区支付平台专用入口；
- 不在本阶段直接应用 ASC、价格或 StoreKit 变更；
- 不以共享英语翻译替代真实设备、票据和当地人工验收。

## Update Rules

- 完成度、样本、人工审校和 ASC 证据只在本矩阵更新；
- 市场顺序变化必须同步更新全球战略和跨版本语言路线；
- 任一市场阻断时优先削减 `v1.8.0` P1，不降低市场质量定义。
