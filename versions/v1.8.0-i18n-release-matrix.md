## Planning Boundary

本矩阵是下一版本草案，不表示西班牙语或巴西葡语已经实现、已在 App Store Connect 公开，或 `v1.8.0` 已进入开发。`v1.7.0 / ASC 1.6.0` 仍只新增韩语；其五语发布结论和英语主语言门禁必须先归档。

`v1.8.0` 只有在以下条件成立后才能进入 Execution Ready：

- `v1.7.0` 已完成发布决定，韩语缺口不再转嫁给下一版本；
- ASC Primary Language 已有 `English (U.S.) / en-US` 的线上证据，或发布负责人确认当前版本可安全切换；
- 西语与巴葡分别锁定术语审校人、20-50 条样本来源和全平台截图范围；
- 产品字符串冻结点与 Review & Close 主线排期已经确定。

## Status Definitions

| 状态 | 含义 |
|---|---|
| Inherited | 从上一版本继承，必须保持不回退 |
| Scheduled | 已绑定本版本，但尚未达到实现或审校门禁 |
| Build | 已有可执行实现，仍缺样本、审校或商店证据 |
| Audit | 实现基本完成，等待人工与发布材料复核 |
| Ready | 六项门禁全部有版本内证据，可公开支持 |
| Blocked | 缺少关键样本、审校、平台能力或发布条件 |

## Locale Contract

| 能力 | 西班牙语组 | 巴西葡语组 |
|---|---|---|
| App UI locale | `es` | `pt-BR` |
| 识别 profile | `es-ES`、`es-MX`，其它拉美地区走显式 fallback | `pt-BR` |
| ASC locale | Spanish (Spain)、Spanish (Mexico) | Portuguese (Brazil) |
| OCR hint 候选 | 以 Vision 运行时支持列表为准，不硬编码宣称 | 以 Vision 运行时支持列表为准，不硬编码宣称 |
| 主要币种 | EUR、MXN；其它拉美币种按样本推进 | BRL |
| 重点场景 | IVA、propina、factura、comprobante、酒店水单 | PIX、CNPJ / CPF 脱敏、NF-e、cartão、酒店水单 |

一个 `es` UI 资源可以服务多个西语地区，但识别规则、ASC metadata 和样本不能假定西班牙与墨西哥完全相同。`pt-PT` 不属于本版本公开范围。

## Sample And Regression Matrix

每个语言组在 Release Candidate 前至少满足：

- 20-50 条脱敏或高拟真的支付、小票、订阅和酒店样本；
- 最小 golden 集覆盖商户、总额、日期、币种和至少两个分类；
- 小数点 / 小数逗号、千分位、税费、折扣、服务费、找零和多金额行；
- 至少一种普通商户小票、一种当地支付场景和一种酒店水单；
- 无真实姓名、邮箱、卡号、订单号、酒店确认号、个人地址或可扫描二维码；
- 新增语言通过后，既有五语离线与 golden 回归仍全部通过。

## Store And English Primary Gate

- Xcode `developmentRegion = en` 是工程回退证据，不证明 ASC Primary Language 已切换。
- ASC Primary Language 的目标是 `English (U.S.) / en-US`；实际状态必须由 App Store Connect audit 或人工截图归档。
- `metadata.yml` 是计划内容真源，不是线上应用或审核通过证据。
- Spanish (Spain)、Spanish (Mexico) 和 Portuguese (Brazil) 必须分别覆盖 App 信息、版本信息、订阅、截图与需要公开的 App Preview。
- 任一新 locale 缺订阅文案、隐私链接、截图或人工审校时，不能在公开描述中宣称完整支持。

## Milestones

1. `L10N-01 Contract`：冻结 locale、地区 profile、术语表、样本责任人与明确非目标。
2. `L10N-02 Recognition`：先扩 Core 语言包、golden case 和 OCR runtime fallback。
3. `L10N-03 UI`：产品字符串冻结后覆盖全部 target，并完成长文本与辅助功能审计。
4. `L10N-04 Regional QA`：完成西班牙、墨西哥与巴西支付 / 小票 / 酒店专项。
5. `L10N-05 Store`：生成全平台截图、metadata、订阅文案和 App Preview。
6. `L10N-06 Release`：母语审校、ASC audit、完整离线回归与真实设备 smoke 全部归档。

## Acceptance

- 新语言 key 集以英语源为基准，主 App 与全部扩展无缺失 key。
- 西语地区 profile 与巴葡 profile 不通过显示文本或 App locale 隐式决定交易 schema。
- OCR 不支持某 locale 时显式回退到通用规则和用户确认，不伪造高置信度。
- 西语与巴葡语言包属于免费基础能力，不进入 Pro gate。
- 新语言不改变账本、备份或 CloudKit schema，不远程热更新可执行识别规则。
- 六项门禁均有当版本证据后，状态才可改为 Ready。

## Non-Goals

- 不在本版本加入第三种新 UI 语言。
- 不把 `es` 宣称为已经优化全部西语国家和地区。
- 不公开 `pt-PT`，也不以巴葡翻译替代欧洲葡语审校。
- 不提供税务、发票合规、报销或金融建议。
- 不因语言扩展上传真实票据、OCR 原文、交易明细或用户纠错内容。

## Update Rules

- 完成度、样本数、审校结果和 ASC 证据只在本矩阵更新，不改写跨版本语言顺序。
- 若产品字符串在冻结后出现非阻断新增，必须推迟文案或重新评估截图 / 审校成本。
- 若任一语言组阻断，应优先削减 `v1.8.0` P1，不降低语言质量定义，也不把缺口静默转移到下一版本。
