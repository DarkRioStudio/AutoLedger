# AutoLedger：个人自动截图记账助手

## 项目概述

AutoLedger 是一个面向 iPhone 用户的个人消费助手，旨在通过 **自动化** 的方式采集消费数据并生成易于理解的账单和分析报告。它的核心目标是让用户不用手动记账，就能清楚地知道自己花了多少、花在了哪里、哪些支出是固定订阅，甚至可以预测下次扣费时间。

在传统记账应用中，用户经常需要逐笔录入或分类，这不仅耗时，还容易遗漏。AutoLedger 通过「支付截图导入 + OCR 抽取 + 规则解析 + 智能分类」的流程，极大简化了这个过程，并以本地处理和隐私保护为原则，让用户享受更轻量的个人财务管理体验。

## 技术选型

- **语言和框架**：采用 **Swift 5** 和 **SwiftUI** 开发 iOS 原生应用。SwiftUI 用于构建声明式 UI，方便快速迭代界面；Swift 作为 Apple 官方推荐的开发语言，能充分利用系统级能力。
- **OCR 与文本解析**：借助 Apple 的 **Vision** 框架实现本地 OCR（`VNRecognizeTextRequest`），并结合正则和关键字抽取规则解析支付成功页面中的金额、商户和时间等信息。
- **数据存储**：首版优先选择 **SQLite**（或 SwiftData）作为本地数据库，确保离线可用且易于迁移。通过 Repository 模式封装数据访问逻辑。
- **AI 分类与分析**：基于简单规则和小模型实现消费分类、订阅检测和月度报告的文本生成；核心账目字段（金额、日期、商户）优先通过确定性规则解析，AI 主要承担辅助分析和建议。
- **项目架构**：整体采用 MVVM 架构分离视图层、状态管理和业务逻辑，配合依赖注入简化测试和替换。
- **隐私与安全**：所有识别和分类逻辑优先在本地设备上运行，不上传原始图片或敏感数据；未来考虑提供加密云同步功能供用户选择。

## 项目目录

```
AutoLedger/
├─ App/                  # 应用入口与全局配置
├─ Features/             # 功能模块（Inbox、Ledger、Subscription、Report、Settings）
├─ Domain/
│  ├─ Models/           # 数据模型：Transaction、Merchant、SubscriptionRule、MonthlyInsight 等
│  ├─ Enums/            # 枚举定义：TransactionType、Category、SourceType 等
│  └─ Services/         # 业务服务：OCRService、ReceiptParser、CategoryClassifier 等
├─ Data/
│  ├─ Persistence/      # 数据持久化：Database、Repository
│  ├─ DTO/              # 数据传输对象
│  └─ Mappers/          # DTO 与 Domain 的转换器
├─ Shared/
│  ├─ Components/       # 通用 UI 组件
│  ├─ Utils/            # 工具方法
│  ├─ Extensions/       # 系统类型扩展
│  └─ Constants/        # 常量
└─ Resources/           # 图片、图标、占位资源
```

此目录结构旨在清晰分离各层职责，便于扩展与维护。开发者可根据需要在目录下新增具体的 Swift 文件和资源。

## 程序工作流

1. **截图导入**：用户通过分享扩展或应用内「+」按钮选择一张支付成功页面截图；系统获取图片并存入临时缓冲区。
2. **OCR 识别**：调用 Vision 框架识别截图中的文本，返回文本块集合。
3. **规则解析**：用正则和关键字匹配抽取金额、商户、时间等结构化数据；若无法确定，则标记为空等待用户编辑。
4. **消费分类**：根据商户名称、金额范围和历史数据进行规则分类；对于难以判断的情况，可调用本地模型或云端服务进行兜底分类。
5. **去重检查**：根据 `dedup_key` 判断是否与已有账单重复；若重复则忽略或更新记录。
6. **存储与同步**：将解析后的账单记录保存到本地数据库；未来可选启用加密云同步。
7. **分析与提醒**：周期性扫描交易数据，识别订阅模式并计算下一次扣费时间；到期前推送提醒；每月生成月度消费报告和异常提示。
8. **界面呈现**：首页展示本月支出总览、近期订阅、分类统计和近期账单列表；用户可进入详情页查看单笔账单并编辑。

通过上述流程，AutoLedger 能够在保障隐私的前提下自动捕捉用户的消费行为，并在需要时提供分析结果和建议。

## 启动页设计

启动页（Splash Screen）是用户打开 App 时的第一视觉，建议采用简洁明快的风格：

- **品牌标识**：中间放置项目 Logo 或应用名称“AutoLedger”，字体简洁现代。
- **标语**：在 Logo 下方使用一句短句，如“轻松捕捉每一笔消费”，表达核心价值。
- **过渡动画**：启动页显示 1–2 秒后平滑过渡到首页；可考虑淡入淡出或简短进度条，避免用户等待过久。
- **暗色/亮色适配**：启动页设计应兼容系统的浅色和深色模式，确保在不同外观下都美观易读。

启动页的主要作用是建立品牌印象和过渡加载资源，不宜放置过多信息。

## 开发顺序建议

基于快速迭代模式，建议按以下顺序完成开发，每个阶段可在 Git 分支中独立迭代并在完成后合并到主干：

1. **项目初始化**
   - 使用 Xcode 创建 SwiftUI 应用工程，配置 Bundle ID 和必要的权限（照片访问、通知等）。
   - 初始化 Git 仓库，并在根目录创建 `AutoLedger` 代码结构。

2. **基础能力搭建**
   - 编写 `OCRService` 及封装 Vision 的文本识别逻辑。
   - 实现 `ReceiptParser`，使用正则匹配和关键词字典抽取金额、商户和时间。
   - 搭建本地数据库以及基础模型 `Transaction`，实现增删改查。

3. **界面与交互**
   - 创建截图导入流程，包括导入入口、OCR 结果预览和确认页。
   - 构建账单列表 `LedgerListView` 与详情 `TransactionDetailView`。
   - 实现月度报告页面 `MonthlyReportView`，呈现分类统计和基本分析。

4. **数据分析与智能功能**
   - 引入 `CategoryClassifier` 完成消费分类规则和模型兜底。
   - 开发 `SubscriptionDetector`，分析周期性交易并生成订阅记录；实现本地通知提醒。
   - 设计月度报告生成器，自动计算环比、环比增长并生成摘要文本。

5. **用户体验优化**
   - 完善去重逻辑、商户归一化和分类学习。
   - 增加快捷指令和分享扩展，允许用户通过系统级入口快速记账。
   - 调整 UI/UX 细节，适配不同屏幕尺寸和深色模式。

6. **测试与发布**
   - 编写单元测试和 UI 测试，确保关键流程稳定。
   - 在 TestFlight 内部测试，收集反馈并修复问题。
   - 根据 App Store 提交要求准备 App Metadata、隐私政策等并发布上线。
