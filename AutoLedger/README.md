# AutoLedger — 截图即记账

> 拍一张支付截图，自动识别金额和商户，一秒入账。

## Features

- **截图记账** — 从相册选取、拍照或粘贴支付截图，自动识别金额、商户和时间
- **一键记账** — 配合 iPhone 操作按钮 + 快捷指令，按一下即可完成记账
- **语音记账** — 首页按住录音，或用 Siri、文本一句话记录支出，不明确时先确认再保存
- **智能解析** — 规则引擎 + LLM 双模式，支持微信、支付宝、App Store、抖音团购等常见支付平台
- **订阅识别与提醒** — 自动识别周期性订阅扣费，预测下次扣费日并提前本地推送提醒
- **自定义分类 / 来源** — 自由增减分类和来源标签，持久化保存，编辑账单时即时生效
- **分类学习** — 记住用户修正历史，同商户后续入账自动使用偏好分类
- **最近删除 & 手动记账** — 误删账单可跨会话恢复；账本右上角可手动录入不依赖截图的账单
- **数据备份与恢复** — 可导出 JSON 备份、从 JSON 覆盖恢复，并开启 iCloud Drive 单文件自动备份
- **酒店消费归档** — 从酒店水单 PDF 或用户主动选择的本地邮箱 PDF 附件生成待确认酒店消费记录
- **多账本** — 管理本地账本、当前账本 / 全部账本口径和默认写入账本
- **多语言支持** — 主路径覆盖简体中文、繁体中文、英文、日文，并通过识别语言包支持多语言账单字段解析
- **账本管理** — 按月/年筛选，随时查阅、编辑每一笔账单
- **月度报告** — 自动汇总本月支出、分类统计和消费趋势
- **商户排名** — 一眼看清消费流向，了解哪家花得最多
- **Share Extension** — 在任意 App 中直接分享截图到 AutoLedger
- **控制中心 Widget** — 从控制中心一键触发剪切板记账，无需解锁进入 App
- **本地优先** — 识别和解析设计为尽量在设备本地完成，保存前建议用户复核解析结果

## Quick Start

### In-App Import

1. 打开 AutoLedger，在首页选择「从相册选取」「拍照识别」或「从剪切板粘贴」
2. 选择一张支付成功截图
3. 等待 1-2 秒，识别结果自动入账

### Action Button Shortcut

1. 添加快捷指令 → [点击安装](https://www.icloud.com/shortcuts/e64528fb5bc34afdab4d7c64242d537e)
2. 前往「设置 → 操作按钮 → 快捷指令」，选择刚安装的「一键记账」
3. 截图支付页面后，按下操作按钮即可自动识别并记账

> 操作按钮仅支持 iPhone 15 Pro 及以上机型。

### Share Extension

在微信、支付宝等 App 中查看支付截图时，点击系统分享按钮，选择 AutoLedger 即可直接导入。

### Control Center Widget

1. 前往「设置 → 控制中心」，添加「剪切板记账」Widget
2. 截图支付页面后，从控制中心点击 Widget，App 自动读取剪切板并记账

### Voice Entry

在首页按住麦克风说出「午饭 28 元」「昨天打车 23.8」等短句，松手后会识别并在高置信度时自动保存；不明确时可确认后保存。账本页仍可点击波形按钮，手动输入同样的一句话，下方账本字段会实时生成并可确认保存。Siri/快捷指令入口会在高置信度时直接保存，不明确时提示重试。

| 支付宝（含 NFC / 碰一下） | ✅ 已支持 |
| App Store / Apple 订阅 | ✅ 已支持 |

## Privacy

- AutoLedger 以本地优先为设计目标
- 默认不需要账号
- OCR 识别和账单解析设计为尽量在设备本地完成
- 保存账单前建议复核解析结果
- 请不要在公开 Issue 中上传真实小票、支付截图或个人财务数据

## Requirements

- iPhone，iOS 17.0 或更高版本
- 推荐 iPhone 15 Pro 及以上（支持操作按钮一键记账）
