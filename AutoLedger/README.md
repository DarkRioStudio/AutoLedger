# AutoLedger — 截图即记账

> 拍一张支付截图，自动识别金额和商户，一秒入账。

## 功能亮点

- **截图记账** — 从相册选取、拍照或粘贴支付截图，自动识别金额、商户和时间
- **一键记账** — 配合 iPhone 操作按钮 + 快捷指令，按一下即可完成记账
- **智能解析** — 规则引擎 + LLM 双模式，支持微信、支付宝、App Store 等常见支付平台
- **账本管理** — 按月/年筛选，随时查阅、编辑每一笔账单
- **月度报告** — 自动汇总本月支出、分类统计和消费趋势
- **商户排名** — 一眼看清消费流向，了解哪家花得最多
- **Share Extension** — 在任意 App 中直接分享截图到 AutoLedger
- **完全离线** — 所有识别和分析在本地完成，不上传任何图片或消费数据

## 快速开始

### 方式一：App 内导入

1. 打开 AutoLedger，在首页选择「从相册选取」「拍照识别」或「从剪切板粘贴」
2. 选择一张支付成功截图
3. 等待 1-2 秒，识别结果自动入账

### 方式二：一键记账（推荐）

1. 添加快捷指令 → [点击安装](https://www.icloud.com/shortcuts/e64528fb5bc34afdab4d7c64242d537e)
2. 前往「设置 → 操作按钮 → 快捷指令」，选择刚安装的「一键记账」
3. 截图支付页面后，按下操作按钮即可自动识别并记账

> 操作按钮仅支持 iPhone 15 Pro 及以上机型。

### 方式三：分享扩展

在微信、支付宝等 App 中查看支付截图时，点击系统分享按钮，选择 AutoLedger 即可直接导入。

## 隐私说明

- 所有 OCR 识别和解析均在设备本地完成
- 不上传任何图片、截图或消费数据到服务器
- 数据仅存储在你的 iPhone 上

## 系统要求

- iPhone，iOS 26.0 或更高版本
- 推荐 iPhone 15 Pro 及以上（支持操作按钮一键记账）
