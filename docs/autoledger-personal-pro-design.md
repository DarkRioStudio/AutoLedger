# AutoLedger 个人 Pro 订阅设计说明

> 文档状态：Active
> 真源范围：Personal Pro 定位、Free / Pro 原则和自动化权益设计
> 最后核验：2026-07-17
> 上位路线图：[ROADMAP.md](ROADMAP.md)

版本：v0.4
日期：2026-07-08
适用范围：AutoLedger 面向个人用户的 Pro 订阅设计
当前目标：在不破坏既有免费体验的前提下，把 Pro 从早期邮箱 / 酒店水单自动化升级为个人账本自动化效率层。

---

## 1. 设计结论

AutoLedger 个人 Pro 不应该被设计成“新增酒店模块收费”，也不应该把此前已经作为基础能力提供给用户的记账、截图识别、手动导入、基础报表等功能突然收回。

新的订阅设计应采用以下模式：

> **免费版：用户可以完整完成记账和水单处理任务。**
> **Pro：系统自动帮用户查找、筛选、批量处理、去重、归档和生成结果，从而节省时间。**

也就是说，Pro 收费的不是“能不能记账”，而是“能不能少做重复劳动”。

AutoLedger Pro 的核心定位：

> **个人自动化效率层。**
> 自动整理账单、水单、订阅扣费和月结资料，减少用户手动查找、下载、导入、确认、去重和整理的时间。

当前 AutoLedger 的产品定位应统一为：

> **本地优先个人账本 + 自动化导入 + 酒店水单归档。**

当前 Pro 的产品口径应统一为：

> **免费版手动完成，Pro 自动整理。**

## 2. 背景

AutoLedger 原有设计更偏本地优先、无账号、轻量可靠的个人记账工具。此前已有的 StoreKit 设计主要是“支持开发者”一次性内购，而不是订阅，也不是 Pro 功能解锁。

现在即将上线“邮箱自动化水单导入”能力。该能力相比传统本地记账功能，会带来更多持续成本：

- 邮箱 provider 适配成本；
- IMAP 登录、搜索、抓取、附件过滤的维护成本；
- 邮件格式、PDF 水单模板、酒店账单样式的长期适配成本；
- OCR / LLM / 规则识别的持续优化成本；
- 异常 case 维护和用户支持成本；
- 批量导入、去重、待确认队列等复杂流程的产品维护成本。

因此，订阅是合理的，但订阅边界必须清楚：

> **用户可以手动完成同样的任务；Pro 负责自动完成重复步骤。**

## 3. 核心原则

### 3.1 不回收既有基础能力

已经作为基础体验出现或已经形成用户预期的能力，不应突然改为付费：

- 手动记账；
- 截图记账；
- 基础 OCR；
- 手动上传 PDF / 图片；
- 手动确认识别结果；
- 基础分类和商户修正；
- 基础订阅记录和提醒；
- 基础月报；
- Widget / Share Extension 的基础入口；
- 基础导出和备份恢复；
- 查看、编辑、删除用户自己的历史数据。

这些能力构成 AutoLedger 的基础信任，不应作为 Pro 的付费墙。

### 3.2 Pro 收费的是省时间

Pro 功能应至少满足以下条件之一：

1. **替用户找东西**：例如从邮箱中自动查找水单、发票、酒店账单。
2. **替用户筛东西**：例如从邮件附件中筛出候选 PDF，而不是让用户自己下载判断。
3. **替用户批量处理**：例如批量导入、批量生成草稿、批量复核。
4. **替用户去重**：例如识别重复水单、重复截图、相似账单。
5. **替用户持续监控**：例如订阅涨价、重复扣费、异常续费。
6. **替用户自动整理结果**：例如自动归档附件、生成月结包、导出凭证索引。
7. **产品侧有持续成本**：例如 provider 适配、规则维护、AI/OCR 成本、异常样本修正。

### 3.3 免费路径必须存在

每个 Pro 自动化能力都应有对应的免费手动路径。

例如邮箱水单：

- 免费用户路径：打开邮箱 → 搜索酒店 / 水单邮件 → 下载 PDF → 分享到 AutoLedger → 手动确认。
- Pro 用户路径：打开 AutoLedger → 扫描邮箱 → 选择候选附件 → 批量生成待确认草稿。

这样用户不会感觉被剥夺功能，而会明确感受到 Pro 在节省时间。

### 3.4 Pro 到期后不锁用户数据

Pro 到期后，用户应继续拥有自己的数据：

- 可以查看历史 Pro 导入的记录；
- 可以编辑历史账单；
- 可以查看已归档的水单附件；
- 可以基础导出自己的数据；
- 不删除、不隐藏、不加密锁住历史记录。

Pro 到期后停止的是新的自动化能力：

- 新的邮箱自动扫描；
- 新的批量自动导入；
- 新的高级去重任务；
- 新的月结包生成；
- 新的订阅异常高级检测；
- 新的高级规则自动应用。

简化表达：

> **Pro 到期后，用户失去自动化，不失去数据。**

## 4. 产品定位

### 4.1 免费版定位

免费版是一款完整可用的本地个人记账 App。

用户可以完成完整记账流程：

- 手动新增账单；
- 截图识别账单；
- 手动导入水单 / PDF / 图片；
- 手动确认识别结果；
- 查看基础统计；
- 管理订阅；
- 使用基础 Widget / Share Extension；
- 导出和备份自己的数据。

### 4.2 Pro 定位

Pro 是个人自动化效率层。

Pro 解决的问题不是“能不能记”，而是：

- 不想手动去邮箱找水单；
- 不想逐个下载 PDF；
- 不想一份一份导入；
- 不想自己判断是否重复；
- 不想月底再手动整理资料；
- 不想自己盯订阅是否涨价或重复扣费。

Pro 的核心价值：

> **少找、少下、少导、少改、少查、少整理。**

## 5. Free / Pro 功能拆分

### 5.1 水单 / 酒店水单模块

| 场景 | 免费版 | Pro |
|---|---|---|
| 导入水单 | 用户手动下载 PDF / 图片后导入 | 自动从邮箱扫描候选水单 |
| 邮件处理 | 用户自己去邮箱搜索、下载附件 | 系统自动搜索邮件、过滤候选附件 |
| PDF 识别 | 单份手动识别 | 批量识别多个附件 |
| 草稿生成 | 手动导入后生成待确认记录 | 批量生成待确认草稿 |
| 去重 | 用户自己判断是否重复 | 系统按邮件、附件、金额、日期、酒店名去重 |
| 归档 | 用户自己保存原始 PDF | 自动把原始邮件 / 附件信息关联到记录 |
| 复核 | 单条复核 | 批量复核队列 |

关键表达：

> 免费版可以手动导入每一张水单；Pro 会帮用户从邮箱里自动找出来、批量识别、去重并放进待确认队列。

### 5.2 截图记账 / OCR 模块

| 场景 | 免费版 | Pro |
|---|---|---|
| 截图识别 | 单张截图识别 | 多张截图批量识别 |
| 识别结果 | 用户逐条确认 | 进入统一待确认队列 |
| 重复截图 | 用户自己发现 | 自动检测重复截图 / 重复账单 |
| 低置信度结果 | 用户自己检查 | 系统集中列出“需要复核”的结果 |
| 规则学习 | 基础商户修正 | 自动把用户修正规则应用到历史和未来记录 |

这里不把截图记账变成付费，而是把“批量、去重、低置信度集中复核、规则自动应用”作为 Pro。

### 5.3 本地账本模块

| 场景 | 免费版 | Pro |
|---|---|---|
| 记账 | 手动新增、编辑、删除 | 批量编辑 |
| 分类 | 单条修改分类 | 批量分类、规则分类 |
| 移动账本 | 单条移动 | 批量移动到账本 |
| 商户整理 | 手动改商户名 | 商户别名合并、自动归一 |
| 历史整理 | 用户自己筛选修改 | 一键应用规则到历史记录 |
| 查找 | 基础搜索 | 高级搜索：金额区间、商户、来源、附件、备注、标签组合 |

这里的 Pro 价值是账单数量增长后的效率提升。

### 5.4 订阅模块

| 场景 | 免费版 | Pro |
|---|---|---|
| 订阅记录 | 手动添加订阅 | 自动从账单中识别周期扣费 |
| 续费提醒 | 基础即将续费提醒 | 汇总未来 7 / 30 / 90 天续费压力 |
| 订阅金额 | 显示当前金额 | 涨价提醒 |
| 重复订阅 | 用户自己检查 | 重复订阅 / 相似订阅检测 |
| 年度成本 | 简单列表 | 年度订阅成本预测 |
| 异常扣费 | 用户自己看 | 金额变化、频率异常、重复扣费提醒 |

订阅模块适合 Pro，因为它能直接帮助用户发现浪费和异常。

### 5.5 报表模块

| 场景 | 免费版 | Pro |
|---|---|---|
| 月报 | 基础收入、支出、分类统计 | 自动月结报告 |
| 分类统计 | 基础分类图表 | 商户排行、标签排行、来源排行 |
| 时间范围 | 默认月 / 年 | 自定义周期、同比、环比 |
| 结论 | 用户自己看图 | 系统自动生成本月变化摘要 |
| 导出 | 基础 CSV / JSON | Excel / PDF 月结包 |
| 凭证 | 用户自己找附件 | 月结包自动带上相关水单 / PDF / 原始附件索引 |

Pro 的报表不应只是“更多图表”，而应强调“月底交付结果”。

### 5.6 导入导出 / 凭证归档

| 场景 | 免费版 | Pro |
|---|---|---|
| 导出 | 基础 CSV / JSON | Excel、PDF、按月打包 |
| 附件 | 单条查看附件 | 凭证归档包 |
| 筛选导出 | 简单导出全部 | 按账本、分类、商户、月份、标签导出 |
| 脱敏 | 手动处理 | 一键脱敏金额、备注、邮箱信息 |
| 交给会计 | 用户自己整理 | 自动生成会计资料包 |

注意：基础导出和备份恢复不应收费。Pro 收费的是高级格式、批量整理、凭证打包和自动归档。

### 5.7 规则和自动分类

| 场景 | 免费版 | Pro |
|---|---|---|
| 分类 | 用户单条选择分类 | 自动分类规则 |
| 商户规则 | 手动修正商户 | 商户别名、关键词规则 |
| 金额规则 | 无或基础 | 按金额区间、币种、账户、备注自动处理 |
| 历史账单 | 用户自己改 | 一键应用规则到历史 |
| 低置信度 | 用户自己判断 | 自动进入待确认队列 |

规则是 Pro 的长期留存点。用户规则越多，AutoLedger 越省时间，迁移成本也越高。

## 6. 当前 Pro 自动化权益范围

当前 Pro 已经不只是酒店水单模块，而是覆盖多个个人账本整理场景的自动化效率层。用户仍然可以用免费版手动完成同类任务；Pro 只减少查找、筛选、批量处理、去重、整理和月结的重复劳动。

当前 Pro 能力以以下 9 项为准：

| Pro 能力 | 用户价值 | 免费替代路径 |
|---|---|---|
| 本地邮箱水单扫描 | 在设备上连接用户授权邮箱，查找可能包含酒店水单 / PDF 附件的邮件 | 用户自己去邮箱搜索、下载 PDF，再手动导入 |
| 专属云端水单收件箱 | 用户主动把水单邮件转发到专属地址，App 拉取候选后仍由用户复核 | 用户继续手动下载 PDF，或使用本地邮箱扫描 / 手动 PDF 导入 |
| 批量候选导入 | 多份水单、截图或附件一次生成待确认候选 | 一份一份导入并逐条确认 |
| 高级去重 | 按邮件、附件、金额、日期、酒店名、商户名等线索解释疑似重复 | 用户自己对照历史记录判断 |
| 高级搜索 | 按金额区间、日期、商户、分类、来源、账本、水单关联和原始币种组合筛选 | 使用基础关键字搜索和手动筛选 |
| 订阅异常提醒 | 发现涨价、疑似重复扣费、周期异常和未来续费压力 | 用户自己检查订阅列表和账单 |
| 月结导出包 | 自动整理交易 CSV、月报 PDF、酒店水单附件索引和 manifest，并打包成 ZIP | 使用基础 CSV / JSON 导出后自行整理 |
| 智能整理建议 | 分析账本，提出商户归一化、分类修正、疑似重复等可解释建议 | 用户手动筛选、逐条改商户和分类 |
| 高级规则自动应用 | 基于已确认别名和分类规则批量预览 / 应用整理结果 | 单条编辑、基础别名和分类学习继续免费 |

注意：

- 手动 PDF / 图片导入不 gate；
- 单条截图 / 拍照 / 相册识别不 gate；
- 手动记账、语音 / 文本输入和快捷指令基础入口不 gate；
- 基础订阅记录和基础提醒不 gate；
- 基础月报、基础 CSV / JSON 导出、备份恢复不 gate；
- 用户历史数据查看、编辑、删除不 gate；
- Support Developer 赞助内购不授予 Pro，也不影响 Pro 订阅。

云端水单收件箱属于服务端成本能力，必须由服务端验证订阅权益；本地 StoreKit 状态只能用于本机 UI 和本地能力展示，不能作为 Worker 安全边界。

## 7. 本地邮箱授权引导设计

邮箱授权是 Pro 转化链路里最敏感的一步，不能只展示一个 IMAP 表单。它需要同时完成三件事：

1. 建立信任：让用户知道 AutoLedger 不会上传邮箱授权码，也不会云端代收邮件。
2. 降低门槛：指导用户选择邮箱 provider，并清楚说明需要填写的是“应用专用密码 / 邮箱授权码”，不是主邮箱登录密码。
3. 明确价值：说明 Pro 不是读取用户邮箱本身，而是为了自动查找水单邮件、筛选 PDF 附件、批量生成待确认草稿。

### 7.1 授权入口

建议有三个入口进入邮箱授权流程：

| 入口 | 场景 | 处理方式 |
|---|---|---|
| 酒店 / 水单模块空状态 | 用户第一次进入水单邮箱导入 | 展示“从邮箱自动查找水单”的价值说明 |
| Pro 权益页 | 用户查看 Pro 功能 | 展示“邮箱水单自动扫描”卡片，点击后进入授权说明 |
| 设置页 | 用户后续管理邮箱授权 | 支持查看连接状态、重新测试、移除本地授权 |

入口文案不要写成“登录邮箱”，建议写成：

> **连接本机邮箱扫描**
> AutoLedger 会在你的设备上连接邮箱，查找可能包含水单的邮件和 PDF 附件。授权码仅保存在本机。

### 7.2 推荐授权流程

建议流程如下：

1. 价值说明页
2. 隐私说明页
3. 选择邮箱 provider
4. 展示 provider 专属授权教程
5. 输入邮箱地址和授权码 / 应用专用密码
6. 本机连接测试
7. 选择扫描范围
8. 执行扫描
9. 展示候选邮件 / 附件
10. 批量导入待确认队列

其中第 1–6 步是“连接邮箱”，第 7–10 步才是“Pro 自动化扫描”。

### 7.3 第一步：价值说明页

标题：

> **自动从邮箱查找水单**

正文：

> 不用再手动搜索邮件、下载 PDF、逐个导入。AutoLedger Pro 可以在你的设备上扫描邮箱，找出可能包含酒店水单、账单或付款凭证的邮件，并生成待确认草稿。

要点：

- 自动查找水单邮件；
- 筛选 PDF / 图片附件；
- 批量生成待确认草稿；
- 自动检测重复水单；
- 所有结果都需要用户确认后才会入账。

按钮：

> **连接邮箱**

次要按钮：

> **我想手动导入水单**

这能明确告诉用户：没有 Pro 或不授权邮箱，也可以继续手动完成任务。

### 7.4 第二步：隐私说明页

这一页非常重要，建议在用户输入邮箱信息前展示。

标题：

> **邮箱授权只保存在本机**

正文建议：

> AutoLedger 不会把你的邮箱授权码上传到服务器，也不会云端代收邮件。扫描时，App 会在你的设备上连接邮箱，只查找与你设置条件匹配的邮件和附件。

可以用四个明确承诺：

- 授权码仅保存在本机 Keychain；
- 不上传邮箱授权码；
- 不上传完整邮箱内容；
- 不会自动入账，扫描结果先进入待确认队列。

建议增加“查看细节”展开区：

| 问题 | 说明 |
|---|---|
| 会读取所有邮件吗？ | 第一版应尽量只读取邮件头、发件人、标题、日期、附件名，以及命中条件的候选附件。 |
| 会上传我的邮件吗？ | 不上传邮箱授权码，不云端代收邮件；若后续某些识别需要云模型，应在发送前单独征得用户同意，并明确脱敏范围。 |
| 可以随时删除授权吗？ | 可以，在设置页移除邮箱连接后，本机授权码和扫描缓存应被删除。 |
| Pro 到期后怎么办？ | 已导入的记录仍可查看和编辑；新的邮箱自动扫描会暂停。 |

### 7.5 第三步：选择邮箱 provider

第一版 provider 建议分成两组：

常用邮箱：

- QQ 邮箱；
- 网易 163；
- 网易 126；
- Gmail；
- Outlook / Hotmail；
- iCloud Mail；
- Yahoo Mail。

高级选项：

- 自定义 IMAP。

每个 provider 卡片应显示：

- 邮箱名称；
- 是否需要应用专用密码 / 授权码；
- IMAP host 和端口是否自动填充；
- 是否需要用户先在邮箱设置中开启 IMAP。

### 7.6 第四步：provider 专属授权教程

不同邮箱的授权方式差异很大，不能只给一个通用说明。建议为每个常用邮箱维护一份本地教程卡片。

教程卡片结构：

1. 打开邮箱安全 / 设置页面；
2. 开启 IMAP / SMTP 服务；
3. 生成应用专用密码 / 授权码；
4. 回到 AutoLedger 粘贴授权码；
5. 完成连接测试。

文案要避免使用“邮箱密码”，推荐统一使用：

> **应用专用密码 / 邮箱授权码**

字段 placeholder：

> 请输入邮箱生成的授权码，不建议填写主邮箱登录密码

对于 Gmail 和 iCloud Mail，要特别提示：某些账号需要先开启两步验证后才能创建应用专用密码；如果账号不支持应用专用密码，则引导用户改用手动导入或未来 OAuth 连接。

### 7.7 第五步：输入与连接测试

表单建议：

| 字段 | 说明 |
|---|---|
| 邮箱地址 | 用户邮箱地址 |
| 授权码 / 应用专用密码 | 本地保存到 Keychain |
| Provider | 已从上一步带入 |
| IMAP Host | provider 预设，支持自定义 |
| 端口 | 默认 993 |
| TLS | 默认开启 |

连接测试时不要立即扫描大量邮件，只做最小验证：

1. DNS / host 可达；
2. TLS 握手成功；
3. 登录成功；
4. 能读取邮箱列表或基础状态；
5. 能执行轻量搜索。

测试成功文案：

> **连接成功**
> 授权码已保存在本机。接下来你可以选择扫描范围，AutoLedger 会查找可能包含水单的邮件。

测试失败文案要具体，不要只显示“登录失败”。

常见失败状态：

| 状态 | 用户提示 |
|---|---|
| 授权码错误 | 授权码无法使用，请确认复制的是应用专用密码 / 邮箱授权码，而不是邮箱登录密码。 |
| IMAP 未开启 | 当前邮箱可能未开启 IMAP 服务，请先在邮箱设置中开启 IMAP。 |
| 需要两步验证 | 该邮箱可能需要先开启两步验证，才能生成应用专用密码。 |
| 网络不可达 | 无法连接邮箱服务器，请检查网络或稍后重试。 |
| TLS 失败 | 安全连接失败，请确认 host、端口和 TLS 设置。 |
| 账号受限 | 该账号可能不允许第三方 IMAP 连接，请改用手动导入。 |

### 7.8 第六步：扫描范围设置

连接成功后，不要默认扫描整个邮箱。先让用户选择范围，体现最小化访问。

建议默认：

- 时间范围：最近 90 天；
- 邮箱范围：收件箱 + 全部邮件可选；
- 附件类型：PDF 优先，可选图片；
- 关键词：酒店、水单、invoice、receipt、folio、statement、付款、账单等；
- 是否包含已拒绝记录：默认不包含；
- 是否跳过已导入附件：默认跳过。

界面文案：

> **选择扫描范围**
> 范围越小，速度越快，也更少读取无关邮件。你可以先扫描最近 90 天。

### 7.9 扫描结果展示

扫描结果不要直接入账，应展示候选列表：

| 信息 | 说明 |
|---|---|
| 邮件标题 | 展示标题，帮助用户判断 |
| 发件人 | 酒店 / 平台 / 银行 / 商户 |
| 邮件日期 | 用于匹配消费日期 |
| 附件名 | PDF / 图片名称 |
| 候选原因 | 例如“标题包含 invoice”“附件名包含 folio”“识别到酒店名和金额” |
| 重复状态 | 已导入 / 疑似重复 / 新候选 |

操作：

- 全选新候选；
- 忽略某封邮件；
- 标记为不是水单；
- 批量导入待确认；
- 查看原始附件。

### 7.10 Pro 付费墙与授权顺序

建议不要让用户先购买后才发现邮箱无法连接。更稳妥的设计是：

- 免费用户可以查看 provider 教程；
- 免费用户可以进行一次连接测试或候选预览；
- 真正的批量扫描、批量导入、高级去重进入 Pro；
- 已购买 Pro 的用户直接进入完整扫描流程。

这样可以减少退款和差评，也能让用户在付费前理解自己的邮箱是否支持。

### 7.11 设置页管理

设置页应提供“邮箱连接管理”：

| 功能 | 说明 |
|---|---|
| 查看连接状态 | 显示邮箱地址、provider、上次连接时间、上次扫描时间 |
| 重新测试连接 | 检查授权码是否仍可用 |
| 修改扫描范围 | 修改默认时间范围、关键词、附件类型 |
| 移除本机授权 | 删除 Keychain 中的授权码和本地扫描缓存 |
| 查看隐私说明 | 解释本地连接和数据处理范围 |

移除授权确认文案：

> **移除邮箱连接？**
> AutoLedger 将删除保存在本机的邮箱授权码，并停止新的邮箱扫描。已导入的账单和水单附件不会被删除。

### 7.12 App Review 与隐私说明要求

邮箱授权属于敏感数据访问，提交审核和产品文案需要清楚说明：

- 为什么需要邮箱授权；
- 授权码保存在哪里；
- 会读取哪些邮件信息；
- 是否上传邮件内容；
- 用户如何撤回授权；
- Pro 到期后数据如何处理；
- 用户不授权邮箱时是否仍能使用手动导入路径。

隐私政策也需要同步更新，明确邮箱授权码、邮件元数据、候选附件、本地缓存和删除机制。

### 7.13 第一版不建议做的授权相关事项

第一版不要做：

- 云端保存邮箱授权码；
- 云端代收用户邮件；
- 后台持续自动扫描；
- 默认扫描整个邮箱历史；
- 默认读取无关邮件正文；
- 未经用户确认直接入账；
- 把用户历史数据绑定在 Pro 订阅内；
- 用“邮箱密码”作为字段名误导用户填写主密码。

第一版要强调的是：

> **本机连接、用户触发、范围可控、结果待确认、授权可移除。**

## 10. 价格建议

第一版 Pro 建议采用 **$2.99 / 月** 作为月付锚点，不建议从 $1.99 / 月起步。

原因：AutoLedger Pro v1 卖的不是去广告、主题、简单限制解除，而是邮箱水单自动扫描、批量导入、高级去重、高级搜索、订阅异常提醒和月结导出包这一组“节省时间的自动化能力”。$2.99 更符合自动化价值，也给后续 provider 适配、PDF 模板维护、识别规则优化和用户支持留出空间。

### 10.1 首发定价

| 套餐 | 建议价格 | 用途 |
|---|---:|---|
| Pro Monthly | **$2.99 / month** | 低门槛试用，建立 Pro 价值锚点 |
| Pro Yearly Early Supporter | **$19.99 / year** | 首发早鸟年付，降低订阅阻力 |
| Pro Yearly Standard | **$24.99 / year** | 功能稳定后的标准年付价格 |

如果第一版只配置两个订阅商品，建议直接使用：

- **$2.99 / month**；
- **$19.99 / year**。

待 Pro 功能稳定、用户对自动化价值形成预期后，再将新用户年付调整为 **$24.99 / year**。

### 10.2 本地化价格参考

App Store 可以使用美元作为主定价锚点，再按价格等级自动本地化。若需要中文区价格感知，可参考：

- 月付：约 **¥18–22 / 月**；
- 年付早鸟：约 **¥128–148 / 年**；
- 年付标准：约 **¥168–188 / 年**。

具体以 App Store Connect 价格等级、汇率和税费展示为准。

### 10.3 为什么不建议 $1.99 / 月

$1.99 / 月更适合轻量高级功能包，例如主题、去广告、基础报表、数量限制解除。AutoLedger Pro v1 已经包含邮箱自动化和批量整理，如果一开始定价过低，后续加入后台扫描、更多邮箱 provider、更多 PDF 模板、发票匹配或 AI 成本后会缺少涨价空间。

因此，建议用 **$2.99 / 月** 建立自动化价值锚点，用 **$19.99 / 年** 降低首发购买阻力。

### 10.4 对用户的定价解释

Pro 页面不要强调“解锁酒店模块”，而应强调：

> **免费版可以手动完成所有核心记账流程；Pro 帮你自动查找水单、批量导入、自动去重、发现订阅异常，并生成月结资料。**

用户购买的是“少花时间做重复整理”，不是“获得自己的数据访问权”。

## 15. 后续个人 Pro 挖掘方向

后续不建议继续横向堆功能入口，优先把当前 Pro 能力串成用户能反复感知的流程：

> 导入 → 待确认 → 去重 → 智能整理 → 异常提醒 → 月结 → 复盘。

### 15.1 推荐优先级

| 优先级 | 方向 | 说明 |
|---|---|---|
| P0 | 统一待处理中心 | 聚合邮箱水单候选、云收件箱候选、OCR 待确认、低置信度结果、疑似重复、订阅异常和智能整理建议 |
| P0 | 月结检查清单 | 把月结包从导出按钮升级为月底收口流程，检查未确认、疑似重复、未归档水单、订阅异常和导出状态 |
| P1 | 规则中心 | 统一商户别名、分类修正、关键词、金额区间、来源和酒店 / 旅行规则，并提供影响预览和撤销 |
| P1 | 智能视图 / Saved Views | 把高级搜索产品化为“本月大额支出”“所有酒店水单”“疑似重复”“订阅扣费”等可保存视图 |
| P1 | 订阅省钱看板 | 展示年度订阅成本、未来续费压力、涨价历史、重复订阅和可能可取消项 |

### 15.2 继续保留在路线图中的方向

- 酒店 / 旅行消费档案：按城市、国家和地区、酒店品牌、平均每晚成本、旅行时间线、历史天气和入住回忆整理个人旅行消费。
- 凭证保险箱 / 附件库：统一管理水单、截图、PDF 和其它凭证，发现缺附件、孤立附件和重复附件。
- 账本健康度 / 自动化健康度：显示未确认、疑似重复、低置信度、未归档水单、订阅异常、最近备份和月结完成状态。
- Mac / iPad 大屏整理工作台增强：强化表格批量编辑、批量分类、批量合并商户、拖拽导入和分组复核。
- 隐私保护型云端辅助：商户别名建议第一版已在用户显式开启、Pro 有效、服务端 entitlement 和脱敏合同成立后接通；后续再评估分类建议、模板识别和月结摘要等更广能力。

### 15.3 暂不进入个人 Pro 的方向

以下方向会把 AutoLedger 拉向财务 SaaS 或团队协作，不属于当前个人 Pro 路线：

- 团队版；
- 会计协作；
- 企业报销审批；
- 银行直连；
- 投资组合管理；

- 把基础导出变成 Pro；
- 把历史数据锁进 Pro。

> **AutoLedger 免费版是一款完整可用的个人账本；AutoLedger Pro 帮你自动整理水单、账单、订阅扣费和月结资料，让账本保持干净。**

更短的口号：

> **免费版手动完成，Pro 自动整理。**

更适合放在付费页的解释：

> 你仍然可以手动导入每一张水单。升级 Pro 后，AutoLedger 会帮你从邮箱中自动查找候选水单，批量生成待确认草稿，并自动识别重复记录。

## 17. 验收标准

Pro v1 上线前应满足：

- 免费用户可以继续完成完整手动记账流程；
- 免费用户可以继续手动导入水单；
- Pro 用户可以完成邮箱水单扫描；
- 邮箱扫描结果进入待确认队列，不直接正式入账；
- Pro gate 文案清楚说明免费替代路径；
- Pro 到期后不影响历史数据查看和编辑；
- 设置页可以查看 Pro 状态、恢复购买、管理订阅；
- Support Developer 内购和 Pro 订阅链路相互独立；
- StoreKit 本地测试覆盖订阅购买、恢复、过期、取消状态；
- 隐私说明明确邮箱授权码本地保存，不上传完整邮箱内容。

## 18. 一句话决策

> **现在可以做订阅，但不要做“功能封锁型订阅”。**
> **AutoLedger Pro 应该是“自动化省时间订阅”：用户免费版能手动完成，Pro 帮用户自动完成重复步骤。**
