## 1. 当前判断

AutoLedger Pro 已经不再只是“酒店水单模块收费”，而是逐步成型为：

> **个人账本自动化效率层。**
> 免费版让用户完整手动完成记账和整理；Pro 帮用户自动发现、批量处理、去重、复核、生成月结资料和保持账本干净。

当前产品定位应继续统一为：

> **本地优先个人账本 + 自动化导入 + 酒店水单归档。**

Pro 的付费逻辑不是“获得自己的数据访问权”，而是：

- 少找：自动从邮箱、专属收件箱、历史账本中找到候选资料；
- 少下：减少用户手动搜索邮件和下载附件；
- 少导：批量导入候选水单、截图或附件；
- 少查：自动发现重复、异常订阅、缺失凭证和待处理项目；
- 少改：批量应用商户、分类和规则整理；
- 少整理：月底生成可归档、可分享、可交付的月结资料。

## 2. 当前已实现 / 已进入 Pro 自动化边界的能力

### 2.1 酒店与水单自动化

- 本地邮箱水单扫描；
- 邮箱候选预览；
- 每月免费 1 次成功导入体验；
- Pro 用户不限本地邮箱水单导入次数；
- 批量候选附件导入；
- 高级去重自动拦截与解释；
- 专属云端水单收件箱；
- Worker 仅处理用户主动转发到专属地址的邮件，不登录用户邮箱；
- 云收件箱走服务端 entitlement 校验，不依赖客户端本地 Pro 状态。

### 2.2 全账本 Pro 自动化

- 高级搜索：金额区间、日期区间、分类、来源、账本、酒店水单关联、原始币种线索等组合筛选；
- 订阅异常提醒：涨价、重复扣费、扣费周期异常、未来 7 / 30 / 90 天续费压力；
- 月结导出包：交易 CSV、月报 PDF、酒店水单附件索引、manifest，并打包为 ZIP；
- 高级规则自动应用：基于已确认的商户别名和分类修正规则，批量预览与应用；
- 智能整理建议：商户归一化、分类修正、疑似重复、批量采纳、忽略、撤销、最近清洗记录；
- 云端辅助建议第一版已接通：用户显式开启且具备 Pro 权益时，App 发送商户键哈希和次数、分类、来源、金额区间等聚合特征，Worker 返回 hash-only 商户别名建议；不发送商户原名、精确金额、备注、OCR 原文或交易 ID，建议仍需用户确认。

### 2.3 继续保持免费的基础能力

以下能力不应进入 Pro 付费墙：

- 手动记账；
- 单张截图 / 拍照 / 相册识别；
- 基础 OCR；
- 手动 PDF / 图片导入；
- 手动复核；
- 查看、编辑、删除历史账单；
- 查看、编辑、删除酒店消费记录和原始 PDF；
- 基础订阅记录和提醒；
- 基础月报；
- 基础 CSV / JSON 导出、备份和恢复；
- Widget / Share Extension 基础入口；
- Support Developer 赞助内购。

核心原则：

> **Pro 到期后，用户失去新的自动化，不失去历史数据。**

## 3. 个人 Pro 后续可以继续挖掘的能力

后续不建议继续横向堆入口，而应把现有能力串成可感知的流程：

> 导入 → 待确认 → 去重 → 智能整理 → 异常提醒 → 月结 → 复盘。

### 3.1 统一待处理中心

目标：把所有需要用户确认的事项集中展示，形成日常 / 每周打开 AutoLedger 的理由。

可聚合事项：

- 邮箱水单候选；
- 云收件箱候选；
- 截图 / OCR 待确认结果；
- 低置信度识别结果；
- 疑似重复账单；
- 订阅异常；
- 智能整理建议；
- 月结前缺资料项。

免费边界：用户仍可在各模块单独处理。
Pro 增强：集中待处理中心、批量复核、批量采纳、批量忽略。

优先级：P0。

---

### 3.2 月结检查清单

目标：把月结包从“导出按钮”升级为“月底收口流程”。

检查项建议：

- 本月是否有未确认记录；
- 是否有疑似重复；
- 是否有低置信度识别结果；
- 是否有未归档水单；
- 是否有订阅异常；
- 是否有大额异常支出；
- 是否已生成月结包；
- 是否已导出 / 分享 / 归档。

免费边界：基础月报继续免费。
Pro 增强：自动检查、完成状态、月结资料包和复核提醒。

优先级：P0。

---

### 3.3 规则中心

目标：把商户别名、分类修正、高级规则自动应用和智能整理建议统一成一个可管理的规则系统。

建议能力：

- 商户别名规则；
- 分类修正规则；
- 来源规则；
- 金额区间规则；
- 关键词规则；
- 酒店 / 旅行规则；
- 订阅识别规则；
- 规则影响预览；
- 规则应用历史；
- 撤销规则影响；
- 规则开关。

约束：任何自动修改历史数据的规则，都必须先预览影响记录，再让用户确认。

免费边界：单条编辑、基础商户别名、分类学习继续免费。
Pro 增强：全账本规则分析、批量预览、批量应用、历史应用记录和撤销。

优先级：P1。

---

### 3.4 智能视图 / Saved Views

目标：把高级搜索产品化，让用户用“视图”理解组合筛选，而不是只看到复杂筛选表单。

内置视图建议：

- 本月大额支出；
- 所有酒店水单；
- 所有多币种消费；
- 未归档凭证；
- 疑似重复；
- 订阅扣费；
- 旅行消费；
- 餐饮高频商户；
- 近 90 天新增商户；
- 需要复核的账单。

免费边界：基础关键字搜索继续免费。
Pro 增强：组合条件、保存视图、快捷入口、视图导出。

优先级：P1。

---

### 3.5 订阅省钱看板

目标：让订阅异常提醒从单点提醒升级为用户能直接感知价值的“省钱看板”。

建议能力：

- 年度订阅总成本；
- 未来 7 / 30 / 90 天续费压力；
- 涨价历史；
- 疑似重复订阅；
- 长期未确认使用的订阅；
- 同商户多笔扣费；
- 扣费周期变化；
- 取消订阅备忘；
- 续费前提醒。

免费边界：基础订阅记录、手动维护和基础提醒继续免费。
Pro 增强：趋势、异常、未来压力、重复检测和年度成本洞察。

优先级：P1。

---

### 3.6 酒店 / 旅行消费档案

目标：把酒店水单归档扩展为个人旅行消费档案，而不是普通报销模块。

建议能力：

- 按城市 / 国家和地区统计酒店消费；
- 酒店品牌统计；
- 平均每晚成本；
- 旅行时间线；
- 入住记录地图；
- 历史天气 + 入住回忆；
- 酒店水单完整性检查；
- 同一次旅行的交通 / 餐饮 / 酒店消费聚合；
- 旅行归档包。

免费边界：查看、编辑和手动导入酒店记录继续免费。
Pro 增强：自动聚合、完整性检查、旅行档案和导出包。

优先级：P1 / P2。

---

### 3.7 凭证保险箱 / 附件库

目标：把水单附件索引升级为统一凭证库。

建议能力：

- 所有附件统一库；
- 按月份、商户、酒店、来源筛选；
- 缺附件账单；
- 孤立附件；
- 附件 hash 去重；
- 本机加密归档说明；
- 导出时自动脱敏；
- 附件与账单关系图；
- 一键补关联。

免费边界：单条记录附件查看继续免费。
Pro 增强：统一附件库、批量筛选、缺失检查、归档包。

优先级：P2。

---

### 3.8 账本健康度 / 自动化健康度

目标：让用户看到“账本是否干净”，而不是只看到收支图表。

评分或状态可以包含：

- 本月未确认记录数量；
- 疑似重复数量；
- 未归档水单数量；
- 订阅异常数量；
- 商户未归一数量；
- 分类未确认数量；
- 低置信度识别数量；
- 月结是否完成；
- 最近备份时间。

免费边界：基础月报继续免费。
Pro 增强：健康度评分、自动化建议、清理任务入口。

优先级：P2。

---

### 3.9 Mac / iPad 大屏整理工作台增强

目标：把 Mac / iPad 端变成重度 Pro 用户的账本整理台。

建议能力：

- 表格批量编辑；
- 多选批量分类；
- 批量合并商户；
- 批量处理重复记录；
- 批量补来源；
- 批量关联水单；
- 拖拽导入 PDF；
- 导入后分组复核；
- 按建议分组处理。

免费边界：单条编辑和基础列表继续免费。
Pro 增强：大屏批量整理、批量规则应用、批量复核和多文件导入。

优先级：P2。

---

### 3.10 隐私保护型云端辅助增强

目标：在不破坏本地优先信任的前提下，为 Pro 用户提供更强的整理建议。

第一版已经完成商户归一化的 opt-in、服务端 entitlement、聚合特征请求、hash-only 响应和本机确认闭环。后续可探索方向：

- 扩充商户归一化别名目录和冲突治理；
- 分类建议云端辅助；
- 酒店水单模板识别增强；
- 订阅异常模型增强；
- 月结摘要生成；
- 跨用户不共享原文，只共享经过独立隐私评审的规则模板或 hash 模式。

硬性边界：

- 默认关闭；
- 用户显式开启；
- Pro 才可用；
- 只上传脱敏聚合特征；
- 不上传真实商户名、金额、备注、OCR 原文、交易 UUID；
- 可随时关闭；
- 有清楚的隐私说明；
- 服务端最小日志、限流、失败回退和删除策略必须在扩大范围前冻结。

第一版仍缺成功响应缓存、持久化 cooldown / backoff、服务端配额、更广别名目录和跨设备授权偏好；这些属于增强项，不应被描述为当前已完成能力。

优先级：第一版已进入 `v1.7.0`；增强项为 P2 / P3。

## 4. 推荐优先级

如果只选 5 个继续推进，建议顺序如下：

| 优先级 | 功能 | 原因 |
|---|---|---|
| P0 | 统一待处理中心 | 聚合现有 Pro 能力，提高日常打开率 |
| P0 | 月结检查清单 | 把月结包变成完整流程，不只是导出按钮 |
| P1 | 规则中心 | 长期留存和迁移成本最高 |
| P1 | 智能视图 / Saved Views | 把高级搜索产品化，更容易理解 |
| P1 | 订阅省钱看板 | 用户能直接感知“可能帮我省钱” |

近期建议先做：

1. 统一待处理中心；
2. 月结检查清单；
3. Pro 口径与文案收口。

不建议当前继续堆新入口，先把现有 Pro 能力串成一条用户能反复感知的流程。

## 5. 不建议当前进入个人 Pro 的方向

以下方向暂不建议进入个人 Pro 当前路线：

- 团队版；
- 会计协作；
- 企业报销审批；
- 银行直连；
- 投资组合管理；
- 信用分 / 贷款建议；
- 财务规划建议；
- 自动正式入账；
- 云端代登录用户邮箱；
- 长期云端保存全部水单 PDF；
- 把基础导出变成 Pro；
- 把历史数据锁进 Pro。

这些会把 AutoLedger 从个人本地优先工具拉向财务 SaaS，成本、审核、隐私和客服都会显著上升。
